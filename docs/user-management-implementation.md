## 实施决策

数据库关联清理在单个写事务中直接完成，同时保存 OSS 清单；无需另设跨事务冻结状态。其他写请求在事务结束后受账号／流程不存在和外键约束阻止，既有审核回写逻辑也重查任务是否存在。文件清理独立持久化，未完成时不报告彻底删除成功。

共享的受保护外键引用会导致整个数据库事务回滚，并提示先解除关联；不扩大删除范围至其他独立资源。OSS 对象仍有在线引用时保留该对象。全局审核脚本的 updated_by 解除关联，保留服务于其他教师的脚本状态。

本期复用现有上传失败补偿清理机制；历史备份、用户已下载文件和过去未被数据库记录的孤立对象不在本次在线数据清理范围。
