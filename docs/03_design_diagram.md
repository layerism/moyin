# 收集表设计图

```mermaid
flowchart LR
  A["管理员端"] --> B["编辑"]

  A --> D["设置"]

  B --> B1["标题与说明"]
  B --> B2["基础题目"]
  B --> B3["DOCX 文件题"]
  B --> B4["AI 脚本绑定"]
  B --> B5["预览与发布"]

  C --> C1["提交列表"]
  C --> C2["检查状态"]
  C --> C3["审核状态"]
  C --> C4["导出数据"]

  D --> D1["学生名单"]
  D --> D2["截止时间"]
  D --> D3["文件自动命名"]
  D1 --> D11["导入名单"]
```

## 用户提交流程

```mermaid
flowchart TD
  S["用户打开收集表链接"] --> F["填写基础信息"]
  F --> L{"姓名与学号是否在学生名单中"}
  L -- "否" --> N["提示不在名单或信息不匹配"]
  N --> F
  L -- "是" --> U["上传 DOCX 材料"]
  U --> V{"必填项与文件规则是否通过"}
  V -- "否" --> E["提示缺失项或格式错误"]
  E --> F
  V -- "是" --> P["提交"]
  P --> R["覆盖该学生上一版提交"]
  R --> M["按规则自动命名文件"]
  M --> O["上传原始 DOCX 到 OSS"]
  O --> Q["创建 AI DOCX 检查任务"]
  Q --> W["后台 Worker 执行检查"]
  W --> X["生成批注文档、评语和检查报告"]
  X --> T["更新检查状态"]
  T --> H["管理员统计页查看结果"]
```

## AI DOCX 处理链路

```mermaid
flowchart LR
  A["原始 DOCX"] --> B["脚本 1：基础格式检测"]
  B --> C["脚本 2：AI 内容评估"]
  C --> D["脚本 3：自动评语填写"]
  D --> E["批注文档"]
  D --> F["检查报告 JSON"]
  D --> G["运行日志"]

  E --> H["OSS 归档"]
  F --> H
  G --> H
  H --> I["统计页展示"]
```

## 模块关系

```mermaid
flowchart TB
  FE["前端 Web"] --> API["FastAPI 后端"]
  API --> DB["PostgreSQL"]
  API --> OSS["阿里云 OSS"]
  API --> TASK["AI 检查任务"]
  TASK --> WORKER["Python Worker"]
  WORKER --> OSS
  WORKER --> SCRIPT["用户配置的 Python 脚本"]
  SCRIPT --> AI["AI 服务"]
  SCRIPT --> OUT["批注与评语结果"]
  OUT --> OSS
  OUT --> DB
```
