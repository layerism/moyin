# 拆分节点导出审核结论与分数

## 需求

节点填写数据 Excel 不再使用混合类型的“审核结论或分数”列，避免后续程序同时解析文本和数值。

## 字段契约

所有带审核脚本的节点统一导出以下审核字段：

`审核状态、审核方式、审核结论、审核分数、审核说明`

- 通过/不通过模式：`审核结论`填写“通过”或“不通过”，`审核分数`为空。
- AI 评分模式：`审核结论`为空，`审核分数`填写数值。
- 人工审核通过：`审核结论`填写“通过”，`审核分数`为空。
- 未提交或审核尚未产生结果：结论与分数均为空。

## 实施边界

- 仅修改工作簿表头和审核行值生成逻辑。
- 不修改数据库、审核结果协议、API 路径、前端下载交互或历史提交。
- 现有 Excel 和资料包下载入口继续共用同一工作簿生成器，因此字段契约保持一致。

## 验证边界

按照项目规则，本任务不运行自动测试、类型检查或浏览器插件；实施后通过表头与行值数量、模式分支和全部调用入口进行静态审计。

## 实施结果

工作簿审核字段已由四列调整为五列。未提交行返回五个空值；人工审核优先写入文本结论，AI 评分仅写入数值分数，其他审核模式仅写入文本结论。Excel 单独下载与资料包下载继续复用同一生成器。
