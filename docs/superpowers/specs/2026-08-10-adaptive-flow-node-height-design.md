# 流程节点自适应高度设计

## 目标

流程节点宽度保持固定，高度随完整标题的换行结果自动增加。所有标题使用统一字号，描述保持统一字号并最多显示两行；节点连接点、连线和画布范围必须同步适配真实高度。

## 节点排版

- 节点宽度固定为 `280px`，最小高度为 `126px`，不设置固定高度和最大高度。
- 标题统一使用 `17px` 字号和 `1.25` 行高，允许完整换行，不限制行数，不使用省略号。
- 描述统一使用 `12px` 字号和 `1.35` 行高，最多显示两行，超出内容使用省略号。
- 节点类型和状态保留独立底部区域，不与标题或描述重叠。
- 删除现有根据文字长度切换标题字号的常规、紧凑、密集模式。

## 高度测量

- 每个画布节点通过 `ResizeObserver` 观察实际渲染高度。
- 画布组件在内存中维护 `nodeId -> height` 映射；尚未完成首次测量时使用最小高度 `126px`。
- 高度是由标题、描述和样式计算出的展示状态，不写入流程数据、草稿或数据库。
- 节点删除后清理对应的高度记录，避免保留无效状态。

## 几何同步

- 连接点坐标使用节点的实际高度计算，顶部连接点保持在 `y`，底部连接点位于 `y + height`。
- 拖拽命中范围、磁吸范围、连接预览、边线路径、边线删除按钮和画布底部边界统一读取实际高度。
- 水平中心和垂直中心分别使用固定宽度与实际高度计算。
- 新节点落点在首次渲染前使用最小高度居中，测量完成后仅更新连线与边界，不回写节点坐标。

## 边界与兼容性

- 不新增依赖，不修改后端接口、数据库或流程节点数据结构。
- 节点宽度、横向连接位置、拖拽坐标和现有画布缩放逻辑保持不变。
- 只修改教师流程画布节点；学生运行时节点和其他卡片不在本次范围内。
- 按项目约束只进行静态业务逻辑审计，不运行测试、构建或浏览器自动化。

## 验收标准

1. 所有流程节点宽度始终为 `280px`，高度不低于 `126px`。
2. 所有节点标题均为 `17px`，完整显示且可增加节点高度。
3. 所有节点描述均为 `12px`，最多显示两行并在超出时显示省略号。
4. 节点高度变化后，上下连接点、连线、命中范围和画布边界保持正确。
5. 动态高度不进入保存数据，不影响历史流程兼容性。
