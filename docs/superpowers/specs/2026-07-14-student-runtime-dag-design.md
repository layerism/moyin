# 学生端 OA 运行拓扑第一版设计

## 目标

学生通过高熵分享链接登录后，看到教师已发布流程版本的只读 DAG 拓扑。学生只能操作当前可填写节点；提交后由服务端自动校验，通过后锁定当前节点并开放满足条件的下游节点。

## 范围

- 学生端按发布快照中的节点坐标和连线显示 DAG。
- 学生画布不提供拖动、连线、删除、排序和配置能力。
- 点击可填写节点后，以弹窗形式填写、暂存或提交。
- `approved` 节点置灰且不可交互；`locked`、`reviewing`、`submitted` 和 `expired` 节点不可填写。
- 自动审核第一版支持必填字段、确认状态、文件扩展名和文件大小校验。
- 自动审核通过后，沿用现有“所有直接上游均通过才开放下游”的 DAG 规则。

## 组件边界

- `StudentFlowTopology`：只读拓扑、直角连线、节点状态和图例。
- `RuntimeNodeDialog`：节点要求、输入控件、暂存和提交操作。
- `StudentRuntimePage`：加载学生实例、维护本地草稿、调用运行时 API 并刷新状态。
- 后端 `validate_submission`：对发布快照中的节点规则和学生提交快照进行确定性校验。

## 状态映射

| 运行状态 | 学生端表现 | 交互 |
| --- | --- | --- |
| `available` | 蓝色高亮、可填写 | 可打开、暂存、提交 |
| `draft` | 蓝色高亮、显示已暂存 | 可继续填写 |
| `rejected` | 红色提示、显示退回 | 可修改并重新提交 |
| `reviewing/submitted` | 显示审核中 | 不可修改 |
| `approved` | 灰色、显示已通过 | 不可交互 |
| `locked` | 弱化、显示待开放 | 不可交互 |
| `expired` | 红色弱化、显示已截止 | 不可交互 |

## 自动审核

提交接口仍以幂等键防止重复提交。服务端在写入不可变提交快照前执行校验：

1. 信息填写节点的所有配置字段均不能为空。
2. 文件节点必须包含文件元数据，并满足扩展名和大小限制。
3. 确认承诺和通知公告节点必须完成确认。
4. 校验失败时不改变节点状态，返回可读错误。
5. `autoApprove=true` 时校验成功后立即进入 `approved` 并计算下游状态；否则进入 `reviewing`。

第一版不执行 Python 或 MJS 文件，仅保留脚本配置；脚本执行器属于后续独立安全模块。

## 验证

- 后端单元测试覆盖各节点类型校验、自动通过和汇聚节点开放。
- 前端纯函数测试覆盖直角路径和画布边界。
- 前端生产构建必须成功。
- 浏览器检查学生拓扑、状态样式、填写弹窗及提交后的节点变化。
