# 单选与多选字段界面重构设计

## 目标

参考用户提供的问卷编辑与填写界面，重构表单填写节点中的单项选择和多项选择字段。保持现有数据结构、答案结构、校验规则及后端接口不变。

## 教师编辑端

- 继续使用现有折叠字段卡片；折叠状态显示字段标题、固定字段类型和普通选项数量。
- 展开状态将字段标题作为顶部主编辑区，标题可直接修改。
- 普通选项纵向排列。每项保留拖拽排序、文本编辑和删除操作。
- 单项选择使用圆形视觉标识，多项选择使用方形视觉标识；标识仅表达题型，不参与编辑端选择。
- 提供“添加选项”操作，沿用现有选项创建逻辑。
- 将布尔式“允许填写其他内容”控件改为“添加‘其他’项”或“移除‘其他’项”操作；底层仍使用现有 `allowOther` 字段。
- 卡片底部只展示固定的“单选题”或“多选题”，不提供字段类型切换。
- 不展示“必填”控件或标签。所有字段继续由数据规范统一视为必填。
- 多项选择继续保留最少选择数和最多选择数设置，避免削弱已有业务能力。

## 学生填写端

- 单项选择不再使用下拉框，改为纵向圆形单选列表。
- 多项选择继续使用纵向方形复选列表，并统一为相同的题目与选项视觉结构。
- “其他”项被选中后继续显示文本输入框。
- 保留已有错误提示、失焦校验、最少和最多选择数提示及答案数据结构。

## 边界与兼容性

- 不增加依赖，不新增字段类型，不修改数据库和后端接口。
- 不允许在已创建字段上切换单选与多选类型；教师应通过顶部新增按钮创建对应题型。
- 历史流程中的 `radio`、`checkbox`、`options`、`allowOther`、`minSelections` 和 `maxSelections` 原样兼容。
- 本次只调整表单填写节点中的单选、多选编辑和学生填写界面，不改动单行文本、多行文本及其他流程节点。

## 验收标准

1. 教师可直接编辑题目标题和普通选项，并完成选项新增、删除、排序。
2. 教师可添加或移除“其他”项；界面中不存在“必填”控件和字段类型选择器。
3. 单选和多选在教师端分别使用圆形、方形视觉标识。
4. 学生端单选以纵向单选按钮展示，多选以纵向复选框展示。
5. 现有答案提交、校验和历史流程数据保持兼容。
