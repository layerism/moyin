# 节点自定义日期时间选择器确认交互设计

## 1. 文档状态

本设计替代 `2026-07-24-node-time-field-confirmation-design.md` 中“确认按钮位于时间输入框旁”的方案。

用户要求“确认”必须位于弹出的日期时间选择器内部。浏览器原生 `datetime-local` 面板无法由网页插入自定义按钮，因此本次改为项目内自定义日期时间选择器。

## 2. 目标

- 点击起始时间或截止时间字段后，打开贴近该字段的自定义日期时间弹层。
- 弹层内提供月份切换、日期网格、小时、分钟和“确认”按钮。
- 弹层打开后，必须点击弹层内“确认”才能关闭。
- 确认后仅更新当前字段并关闭日期时间弹层，节点设置弹窗保持打开。
- 移除字段旁现有的“确认”按钮，保留“清除”。
- 不修改后端、时间数据结构、流程保存、发布或修订规则。

## 3. 方案选择

采用无第三方依赖的轻量自定义弹层：

- 使用 React 组件状态管理当前月份、选中日期、小时和分钟；
- 使用 JavaScript `Date` 完成本地日期计算与 ISO 转换；
- 使用 React portal 将交互遮罩和选择器挂载到 `document.body`，避免被节点设置弹窗的 `overflow: hidden` 裁切；
- 使用触发控件的 `getBoundingClientRect()` 计算弹层位置，并在空间不足时自动显示在字段上方；
- 沿用项目现有白色面板、灰色细边框、蓝色主按钮和圆角。

不引入日期组件库，不复用浏览器原生日期面板，不新增后端能力。

## 4. 组件边界

新增一个面向节点时间字段的前端组件 `NodeDateTimePicker`，职责仅包括：

- 展示当前已确认时间；
- 打开和关闭自定义日期时间弹层；
- 维护弹层内的临时选择；
- 将确认后的本地日期时间转换为 ISO 字符串；
- 通过 `onConfirm` 回传确认结果；
- 在关闭后把焦点返回触发控件。

建议接口：

```ts
type NodeDateTimePickerProps = {
  ariaLabel: string;
  disabled?: boolean;
  onConfirm: (value: string) => void;
  value: string | null;
};
```

组件不读取流程对象，不调用 API，也不判断起始时间与截止时间的业务关系。`NodeInspector` 继续负责把结果映射到 `startAt` 或 `deadlineAt`。

## 5. 打开与初始化

### 5.1 触发控件

原生 `datetime-local` 输入替换为外观保持一致的只读触发按钮：

- 显示格式继续为本地 `YYYY/MM/DD HH:mm`；
- 未设置时显示现有空值提示；
- 保留日历图标；
- 鼠标点击或键盘 `Enter`、空格均可打开；
- 外层 `fieldset` 禁用时不能打开。

### 5.2 初始选择

打开弹层时：

- 当前字段已有时间：选择器初始化为该时间；
- 当前字段为空：初始化为打开瞬间的本地日期和时间，秒与毫秒归零；
- 月历定位到初始化时间所在月份；
- 起始时间与截止时间分别独立初始化，不共享临时选择。

任何弹层内操作只修改临时选择，不调用 `onUpdateNode`。

## 6. 弹层内容

### 6.1 月历

- 顶部显示当前年、月；
- 提供上一个月和下一个月按钮；
- 星期标题按“日、一、二、三、四、五、六”排列；
- 日期区域固定为六行七列，补齐相邻月份日期，避免月份切换时面板高度跳动；
- 当前选中日期使用蓝色主选中态；
- 今天使用轻量描边或文字强调，不与选中态冲突；
- 点击相邻月份日期时，同时切换月份并选中该日期。

月份切换需要正确处理不同月份天数。例如从 31 日切换到没有 31 日的月份时，将日期收敛到目标月份最后一天。

### 6.2 时间

- 提供小时和分钟两个滚动选择列；
- 小时范围为 `00`–`23`；
- 分钟范围为 `00`–`59`；
- 当前小时和分钟使用蓝色选中态；
- 选择精度保持到分钟，确认时秒与毫秒为零。

### 6.3 确认

- “确认”按钮位于日期时间弹层内部底部；
- 点击后将当前本地日期、小时和分钟构造为 `Date`；
- 转换为 ISO 字符串后调用当前字段的 `onConfirm`；
- 更新完成后关闭日期时间弹层；
- 节点设置弹窗不关闭；
- 焦点返回刚才的时间字段触发控件。

由于空字段打开时会自动初始化为当前本地时间，弹层始终存在可确认的完整日期时间，不会形成无法退出的空状态。

## 7. 强制确认与交互隔离

日期时间弹层打开后采用严格交互边界：

- 在节点设置弹窗上方铺设透明交互遮罩；
- 遮罩拦截节点设置弹窗及背景页面的点击、滚动和触摸；
- 点击遮罩不关闭日期时间弹层；
- `Escape` 不关闭日期时间弹层；
- 不提供“取消”或右上角关闭按钮；
- 不能切换到另一个时间字段；
- 只能在日期时间弹层内选择并点击“确认”退出。

键盘焦点限制在日期时间弹层内部，`Tab` 和 `Shift+Tab` 在弹层可操作元素间循环。弹层打开后聚焦当前选中日期；确认关闭后焦点返回触发控件。

节点设置原有背景锁定继续生效。日期时间弹层只增加更高一层的局部交互锁，不改变节点设置关闭规则。

## 8. 节点字段行为

### 8.1 起始时间

确认起始时间时仅执行：

```ts
onUpdateNode(node.id, { startAt: confirmedIsoValue });
```

### 8.2 截止时间

确认截止时间时仅执行：

```ts
onUpdateNode(node.id, { deadlineAt: confirmedIsoValue });
```

两个字段相互独立。确认一个字段不会修改或打开另一个字段。

### 8.3 清除

字段旁保留现有“清除”按钮：

- 点击后立即把对应节点字段写为 `null`；
- 不打开日期时间弹层；
- 不关闭节点设置弹窗。

字段旁不再显示“确认”按钮。

## 9. 校验与数据流

确认后的数据流：

```text
节点已确认时间
  -> 打开自定义日期时间弹层
  -> 初始化临时日期、小时、分钟
  -> 用户在弹层内调整
  -> 点击弹层内“确认”
  -> 本地 Date 转换为 ISO 字符串
  -> NodeInspector 调用既有 onUpdateNode
  -> 当前页面流程工作副本更新
  -> 关闭日期时间弹层
  -> 节点设置弹窗保持打开
```

继续由现有 `getTimeWindowStatus(node)` 和 `getTimeWindowSummary(node)` 读取已确认节点值。起始时间不早于截止时间时，沿用现有错误提示，不在日期选择器内新增跨字段阻断逻辑。

## 10. 定位与响应式

### 10.1 桌面端

- 弹层优先显示在触发字段下方；
- 下方空间不足时显示在字段上方；
- 水平方向限制在视口安全边距内；
- 弹层层级高于节点设置弹窗和其遮罩；
- 字段本身恢复为“时间触发控件 + 清除”两列布局。

### 10.2 窄屏

- 弹层宽度不超过视口安全范围；
- 月历与时间选择区域允许由并排改为上下排列；
- 弹层内容超出可用高度时，仅弹层内部滚动；
- 页面、流程画布和节点设置主体保持锁定；
- “确认”按钮始终位于弹层内部且可到达。

## 12. 验收标准

1. 点击起始时间或截止时间字段会打开项目自定义日期时间弹层。
2. 弹层包含月份切换、六行日期网格、小时、分钟和内部“确认”按钮。
3. 字段旁不再显示“确认”按钮。
4. 弹层打开后，点击外部、滚动外部、触摸外部或按 `Escape` 均不能关闭或操作节点设置。
5. 弹层不提供取消或关闭控件，只能点击内部“确认”退出。
6. 已有时间按原值初始化；空字段按当前本地时间初始化。
7. 弹层内选择未确认前不更新节点状态、摘要或流程工作副本。
8. 点击“确认”后仅更新当前字段并关闭日期时间弹层。
9. 确认后节点设置弹窗保持打开，焦点返回当前时间字段。
10. 字段旁“清除”继续立即清除对应节点时间。
11. 起始时间与截止时间相互独立。
12. 月份切换、月底收敛、跨年和相邻月份日期选择逻辑正确。
13. 桌面端弹层不被节点设置裁切；窄屏下仅弹层内部滚动且确认按钮可到达。
14. 现有时间状态、先后顺序提示、编辑锁定和发布后修订规则保持不变。
15. 不增加第三方依赖，不修改后端、接口或数据结构。

## 13. 验证边界

按项目约定，开发期间不运行自动化测试、构建、TypeScript 编译或浏览器自动化，只执行静态状态流、日期边界、焦点和样式审计。实现完成后清理项目缓存，使用本地 Uvicorn 与 Vite 重启服务，由用户依据上述验收标准手动验证。
