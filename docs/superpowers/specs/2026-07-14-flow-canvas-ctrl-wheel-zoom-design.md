# 流程画布 Ctrl + 滚轮缩放设计

## 目标

教师流程设计画布与学生流程图均支持 `Ctrl + 滚轮` 缩放，以便查看大规模 DAG，同时保留既有的普通滚动与教师端拖拽平移行为。

## 交互规则

1. 默认缩放比例为 `100%`，允许范围为 `50%` 至 `150%`。
2. 仅在按住 `Ctrl` 时拦截滚轮事件并执行缩放；未按 `Ctrl` 时维持原有滚动行为。
3. 每次滚轮变化按低灵敏度换算，单次比例变化约为 `2%`，避免缩放过快。
4. 以指针在画布中的位置为锚点，缩放后该位置对应的流程坐标保持稳定。
5. 教师端缩放不影响节点拖拽、连线、自动布局与保存；学生端缩放不影响节点状态、填写、暂存或提交。

## 实现边界

- 提取无副作用的缩放计算函数，输入当前比例、滚轮位移、指针位置和滚动容器状态，输出受限后的比例与新滚动位置。
- 教师端和学生端分别持有视图比例状态，但复用同一计算函数。
- 用 CSS `transform: scale(...)` 缩放流程内容，并按比例调整画布可滚动尺寸。
- 不新增服务端接口、数据库字段或持久化配置。

## 验收标准

1. `Ctrl + 滚轮上滚` 放大，`Ctrl + 滚轮下滚` 缩小。
2. 连续滚动时比例变化平缓，且始终位于 `50%`–`150%`。
3. 指针附近的节点在缩放后保持视觉位置，不发生明显跳跃。
4. 普通滚轮仍可滚动画布或页面。
5. 教师和学生两类流程图均可正常缩放，现有单元测试与生产构建均通过。
