# 教师进度面板现代化视觉重设计

> 状态：概念与实施方向已确认。参考概念图：`/ai/.codex/generated_images/01a021f5-6409-7df0-a962-4c7512dfd841/exec-8c0b10dc-43f9-4a1a-959f-a2d02482bde2.png`。

## 目标与边界

仅重设计“学生填写进度”面板的信息层级和视觉表达，提高管理界面的厚重感、现代感与业务可读性。保留现有进度读取、节点数据导出、材料下载、延期、提交详情、人工审核及三横线菜单逻辑；不修改后端接口、数据结构和运行状态规则。

## 信息结构

1. 标题区：保留“流程运行管理”“学生填写进度”和关闭操作，压缩高度并强化深色标题层级。
2. 错误反馈：仅在存在错误或结果消息时显示紧凑告警条；不再为空消息长期预留高度。
3. 进度概览：从当前 `progress.students` 派生学生总数、已完成、进行中、有逾期四项真实统计，使用一个分段统计栏，不创建零散卡片。
4. 数据操作：将节点填写数据导出和材料下载合并为一个统一操作面板，桌面端双列排列，小屏纵向排列。
5. 学生表格：保持六列结构；状态改为语义标签，完成数增加细进度条，逾期仅在非零时强调，操作继续使用现有三横线菜单。

## 视觉系统

- 主表面：`#ffffff`；内容背景：`#f6f8fb`；柔和表头：`#f2f5f9`。
- 主文字：`#172033`；次级文字：`#667085`；边框：`#d7dee8`。
- 主操作：`#2563eb`；完成：`#079455`；错误及逾期：`#d92d20`。
- 圆角：主要容器 12px，控件 8px；不使用渐变、光晕或装饰插画。
- 阴影：仅用于面板、操作区和表格外框，保持低透明度。
- 标题使用 700–800 字重；表格和控件明确设置字号、行高与字重，不依赖浏览器默认值。

## 可见文案

只保留现有或已确认文案：“流程运行管理”“学生填写进度”“学生总数”“已完成”“进行中”“有逾期”“数据操作”“节点填写数据”“导出 Excel”“下载范围”“下载材料”及现有表头、状态、菜单和反馈文本。不增加说明性副标题、装饰标签或无业务价值提示。
