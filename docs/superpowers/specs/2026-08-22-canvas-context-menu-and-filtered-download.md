# 画布手形平移、节点右键菜单与筛选下载

> 状态：交互与业务逻辑已确认。

## 目标

将流程画布当前的“右键直接平移”和节点外置快捷操作栏统一调整为：

1. 按住 `Alt` 时显示手形工具，使用 `Alt + 鼠标右键拖动`平移画布；
2. 普通右键节点时打开节点操作菜单；
3. 菜单固定包含“设置、删除、下载”，但严格遵守草稿、发布和修订权限；
4. 下载不再立即打包，而是先打开可选择下载内容和学生范围的配置弹窗。

## 画布与节点手势

- 按下 `Alt` 后，画布进入手形提示状态，光标显示为张开的手。
- 在画布任意位置（包括节点或连线）按下 `Alt + 右键`后开始平移，光标变为抓紧的手。
- 平移一旦开始，即使中途松开 `Alt`，也持续到右键释放；释放后不得弹出节点菜单。
- 普通右键节点时，将该节点设为唯一活动节点并在鼠标位置打开菜单。
- 普通右键空白区域只关闭已有菜单，不平移画布，也不显示浏览器原生菜单。
- `Ctrl + 左键`逐个多选、左键节点拖动、左键框选、`Ctrl + 滚轮`缩放、节点连线和双击设置继续保留。
- 画布在捕获阶段处理 `Ctrl + 滚轮`并阻止浏览器原生页面缩放；兼容将主控制键报告为 `Meta` 的客户端键盘映射。
- 手形状态同时依据捕获阶段键盘事件和画布指针事件中的 `Alt`/`AltGraph` 修饰状态同步，避免子控件阻断冒泡或右 `Alt` 键报告差异导致状态丢失。
- 菜单在点击外部、按 `Escape`、开始平移/缩放/节点拖动、选择菜单项、切换流程或窗口失焦时关闭。
- 键盘聚焦节点后，`Shift + F10`打开同一菜单。

## 节点菜单权限

菜单固定显示“设置、删除、下载”，不可用项必须同时具备视觉禁用和事件层权限校验。

| 节点状态 | 设置 | 删除 | 下载 |
| --- | --- | --- | --- |
| 草稿节点 | 可用 | 可用 | 禁用，发布后可下载 |
| 已发布且未解锁 | 禁用，先解锁编辑 | 禁用 | 可用 |
| 修订中的既有发布节点 | 可用，但沿用发布后字段限制 | 禁用 | 可用，下载当前发布版本 |
| 修订中新增且尚未发布的节点 | 可用 | 可用 | 禁用，重新发布后可下载 |

删除权限以节点是否已经进入当前发布版本为准：既有发布节点即使处于修订状态也始终不可删除；修订中新建节点在重新发布前可以删除，进入新发布版本后立即不可删除。菜单不得绕过现有 `canDeleteNode`、`canEditRevisionNodeCore` 和发布节点集合判断。

现有节点右侧设置、删除、下载快捷操作栏移除；双击设置入口继续保留。

## 下载配置弹窗

点击可用的“下载”后关闭节点菜单并打开弹窗。弹窗包含：

- 下载内容：填写数据 Excel、学生提交文件，至少选择一种；
- 学生搜索：按姓名或学号匹配；
- 节点状态筛选：全部、未提交、审核中、已通过、未通过、审核异常；
- 学生勾选：默认选择全部有效名单学生，可全选当前筛选结果或逐个选择；
- 汇总信息：筛选人数、已选人数、文件人数、文件数量和总大小；
- 主按钮根据内容显示“下载 Excel”“下载文件”或“下载资料包”。

学生范围同时作用于 Excel 和学生文件。Excel 对所选未提交学生保留空业务行；文件只取所选学生当前有效尝试中状态为 `reviewing`、`approved`、`rejected` 或 `audit_error` 的文件，不包含历史尝试，没有文件的学生不创建空目录。

表单或公告节点没有学生文件时禁用文件选项；只选文件且所选学生没有文件时禁用下载。下载失败时保留弹窗和选择并显示红色错误，下载成功后不显示成功提示。

## 后端契约

新增节点下载预览接口，返回节点标题、有效名单学生的稳定名单记录 ID、姓名、学号、当前提交状态、提交时间、文件数量和文件总大小。不得返回填写内容、存储键或下载地址。

正式下载使用 `POST`，请求体明确区分全部学生和所选学生，避免用空数组同时表达“全部”和“无选择”：

```json
{
  "includeWorkbook": true,
  "includeFiles": true,
  "studentScope": "selected",
  "rosterEntryIds": [101, 102, 108]
}
```

服务端重新校验教师归属、发布版本、节点归属、有效名单和所选名单记录；下载时以当前有效尝试为准。选择的名单记录已经失效时返回冲突错误，前端保留弹窗并要求刷新学生范围。

## 实施范围

- 前端：画布键盘/指针状态、节点右键菜单、下载配置弹窗、下载 API 和样式。
- 后端：下载预览、筛选请求模型、节点导出查询过滤、Excel/文件可选归档响应。
- 不修改数据库结构、发布快照、学生提交状态或学生端页面。
