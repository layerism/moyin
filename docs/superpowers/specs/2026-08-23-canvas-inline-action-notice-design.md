# 画布标题栏内联操作提示

> 状态：方案已确认。本设计只移动教师流程设计器操作提示的展示位置，不改变提示触发条件、业务状态或错误处理。

## 目标

取消流程摘要与流程网格之间由操作提示单独占用的纵向行，将统一操作提示嵌入既有“流程画布”标题栏，使提示出现和消失时均不改变画布可用高度。

## 展示规则

- 画布标题栏从左到右依次为“流程画布”、操作提示和缩放比例。
- 操作提示沿用当前红色错误语义，不增加背景、边框或额外高度。
- 提示保持单行；空间不足时省略，`title` 保留完整提示内容。
- 发布或重新发布成功时，不再展示完整分享 URL，而显示紧凑的“打开学生链接”；链接地址、打开方式和安全属性保持不变。
- 缩放比例固定在标题栏最右侧，不被提示文本挤压。
- 窄屏优先保留画布标题和缩放比例，提示占用剩余空间并自动省略。
- 暂存、发布、预览、连线、模板操作等所有现有 `actionNotice` 分支继续使用同一展示出口。

## 实施范围

- `frontend/src/features/academic-flow/AcademicFlowDesigner.tsx`：移除工作区独立提示行，将提示和分享链接传入画布组件并在标题栏渲染。
- `frontend/src/styles.css`：增加标题栏左侧摘要布局、单行省略和链接固定宽度规则，删除独立提示行的外边距。

不修改后端接口、流程数据、提示触发条件、画布手势、节点权限或学生端页面。

## 验证边界

按项目规范不运行自动测试、构建或浏览器插件。完成前静态核对所有 `setActionNotice` 与 `setPublishedShareUrl` 分支、组件参数、标题栏收缩规则和响应式层叠；随后本地重启服务并核对监听端口及进程工作目录。
