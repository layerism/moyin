# 节点双击打开设置设计

## 目标

教务流程设计器中的节点支持通过双击快速打开现有“节点设置”面板，减少先选中节点再点击齿轮按钮的操作成本。

## 交互规则

- 单击节点继续执行现有选中逻辑，不改变选中态和快捷操作区。
- 草稿流程或已解锁修订状态下，双击节点打开该节点的现有设置面板。
- 已发布且尚未点击“解锁编辑”时，双击节点不执行任何操作，也不自动进入修订状态。
- 双击节点内部的连接端口时不打开设置，避免干扰连线操作。
- 齿轮“配置节点”入口继续保留，键盘和触屏用户仍可使用现有显式入口。

## 实现边界

仅修改 `FlowNodeCanvas` 中节点按钮的事件绑定：增加双击事件，在 `locked` 为假且事件目标不属于 `.connection-port` 时调用现有 `onOpenInspector(node.id)`。不新增组件、状态、接口、数据库字段或后端逻辑。

节点设置面板继续使用现有权限能力：发布后修订中的历史节点只开放已允许修改的字段，本功能不扩大任何节点编辑权限。

## 验证边界

按项目约定不运行自动化测试、构建或浏览器测试，仅做静态差异审计。用户手动验证以下场景：

1. 草稿节点双击可打开节点设置。
2. 已发布未解锁时双击无响应。
3. 解锁编辑后双击可打开节点设置，历史节点字段限制保持不变。
4. 单击选中、拖动节点、连接端口和齿轮入口保持原行为。
