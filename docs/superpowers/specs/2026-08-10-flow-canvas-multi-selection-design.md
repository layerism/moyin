# 流程画布框选与整体移动设计

## 目标

教师在流程画布空白区域按住鼠标左键拖动时，可以通过选择框一次选中多个可移动节点；随后拖动任一已选节点，可保持节点间相对位置并整体移动。

## 交互规则

1. 鼠标左键从画布空白区域按下并拖动时启动框选。
2. 节点矩形与选择框相交即进入多选集合，不要求被完全包围。
3. 框选仅包含当前允许移动的节点；已发布并锁定的节点自动排除。
4. 多选节点统一显示现有蓝色选中样式。
5. 拖动任一已选节点时，全部已选节点保持相对位置整体移动。
6. 整组移动沿用现有 16px 网格吸附。位移以拖动锚点节点为基准计算一次，再应用到整组节点。
7. 当任一节点即将越过画布左侧或顶部最小边界时，统一约束整组位移，不改变节点之间的距离。
8. 点击空白区域且未形成有效拖动时清空多选；点击未选节点时切换为该节点单选。
9. 多选状态下仅当前活动节点显示设置与删除快捷操作，避免把单节点删除误解为批量删除。
10. 双击节点打开设置、连接点拖线、右键拖动画布、Ctrl+滚轮缩放保持现有行为。

## 状态与组件边界

`FlowNodeCanvas` 负责短生命周期的画布交互状态：

- 已选节点 ID 集合；
- 选择框的起点与当前点；
- 整组拖动开始时的指针位置和节点初始位置快照；
- 当前手势属于框选、节点拖动、连线或画布平移的判定。

`AcademicFlowDesigner` 继续负责流程草稿数据。它向画布提供批量更新节点位置的回调，使一次指针移动只生成一次流程状态更新，避免连续调用现有单节点更新函数时相互覆盖。

多选集合不写入流程配置，也不进入后端、数据库或发布版本；它仅属于当前页面会话的界面状态。

## 坐标与命中计算

选择框起止点通过现有 `getCanvasPoint` 转换为未缩放的画布坐标，从而抵消当前视口平移量和缩放倍率。

节点命中区域使用其当前 `x`、`y`、固定宽度和实际渲染高度。选择框与节点矩形满足水平、垂直方向均有交集时视为命中。

整体拖动记录所有已选节点的初始坐标。拖动过程中先计算锚点节点吸附后的位移，再根据整组最小 `x`、`y` 统一限制位移，最后批量生成新坐标。连线继续使用更新后的节点位置自动重绘。

## 状态清理

- 节点删除后，从多选集合和拖动快照中移除对应 ID。
- 流程节点列表整体切换时，清除不再存在或不可移动的 ID。
- 画布进入锁定状态时，取消框选和整体拖动并清空多选集合。
- 指针取消时，释放捕获并终止当前框选或拖动，不提交额外位置变化。

## 视觉表现

选择框使用绝对定位的半透明浅蓝背景、蓝色描边和 `pointer-events: none`，固定放置在连线层之上、节点层之下，不阻挡节点交互。框选过程中画布禁止文本选择。

现有单节点选中样式复用于多选节点，不新增不同颜色或批量操作工具栏。

## 实施范围

预计修改：

- `frontend/src/features/academic-flow/AcademicFlowDesigner.tsx`
- `frontend/src/features/academic-flow/canvasPan.ts`
- `frontend/src/styles.css`

矩形标准化、相交判断和整组边界位移计算作为纯函数放入现有 `canvasPan.ts`，不新增模块。

不修改：

- 后端接口与数据库；
- 流程节点、连线数据结构；
- 学生端拓扑画布；
- 批量删除、复制、对齐等未提出功能；
- 右键平移和现有缩放快捷方式。

## 审计标准

按项目约定不运行浏览器插件、构建或自动化测试，仅进行业务逻辑静态审计：

- 框选、节点拖动、连线和右键平移手势互斥；
- 缩放和平移后坐标换算保持一致；
- 批量位置更新只产生一次草稿状态提交；
- 锁定节点不会进入多选或被整体移动；
- 节点间相对位置在边界约束下保持不变；
- TypeScript 类型和补丁格式无明显问题。
