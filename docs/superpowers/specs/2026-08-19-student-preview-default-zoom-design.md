# 学生端默认缩放设计

## 目标

教师从流程设计器打开真实学生预览，以及正式学生打开流程时，办理拓扑均默认以 50% 显示，与教师流程设计画布保持一致，便于一次查看更多节点。

## 方案

- `StudentFlowTopology` 的缩放状态初始值由 `1` 调整为 `0.5`。
- 教师学生预览和正式学生运行页复用该组件，因此不增加预览专用分支或参数。
- 组件后续仍由现有 `Ctrl + 滚轮` 交互更新缩放状态。
- 继续使用现有 50%–150% 缩放边界、画布平移、节点坐标和连线路径逻辑。

## 范围边界

- 仅改变学生拓扑的初始缩放比例，覆盖教师学生预览和正式学生运行页。
- 不改变教师流程设计画布、浏览器页面缩放或后端预览数据。
- 不持久化缩放值，不增加用户配置。
- 本次遵守学生预览一致性原则：预览与正式学生端复用同一拓扑组件、相同交互和相同配置解释，不建立预览专用可见分支。

## 验收条件

1. 教师打开学生预览时，办理拓扑初始缩放为 50%。
2. 正式学生打开流程时，办理拓扑初始缩放同样为 50%。
3. 两种页面均可继续通过现有交互在 50%–150% 范围内缩放和平移。

## 验证边界

项目规范禁止代码功能改动过程中运行测试或使用浏览器插件。本次仅进行静态属性传递、状态初始化和缩放调用链审计，并在交付时明确未运行自动化测试及浏览器回归。
