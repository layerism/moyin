# 学生预览默认缩放设计

## 目标

教师从流程设计器打开真实学生预览时，办理拓扑默认以 50% 显示，便于一次查看更多节点。正式学生运行页继续默认以 100% 显示。

## 方案

- `StudentFlowTopology` 增加可选的 `initialZoom` 参数，默认值为 `1`。
- 组件的缩放状态仅在首次挂载时使用该参数初始化，后续仍由现有 `Ctrl + 滚轮` 交互更新。
- `StudentRuntimePage` 根据已有 `preview` 标记传入 `0.5` 或 `1`。
- 继续使用现有 50%–150% 缩放边界、画布平移、节点坐标和连线路径逻辑。

## 范围边界

- 仅改变教师真实学生预览的拓扑初始缩放比例。
- 不改变正式学生页面、教师流程设计画布、浏览器页面缩放或后端预览数据。
- 不持久化缩放值，不增加用户配置。

## 验收条件

1. 教师打开学生预览时，办理拓扑初始缩放为 50%。
2. 正式学生打开同一流程时，办理拓扑初始缩放仍为 100%。
3. 两种页面均可继续通过现有交互在 50%–150% 范围内缩放和平移。

## 验证边界

项目规范禁止代码功能改动过程中运行测试或使用浏览器插件。本次仅进行静态属性传递、状态初始化和缩放调用链审计，并在交付时明确未运行自动化测试及浏览器回归。
