# 节点配置统一存储

状态：用户已确认会话方案并授权备份、检查点提交及实施。此文记录已批准的范围，不新增审批环节。

## 目标

节点当前配置仅维护在 `flows.draft_config.nodes`。移除 `publishedNodeParameters` 与两张审核参数表；保留发布版本、学生状态、提交、审核任务和历史记录。可编辑参数保存即生效；未发布结构不能进入正式运行。接口可保留，但内部共享读写逻辑。

## 设计

- 后端字段白名单定义允许实时读取/编辑的字段。普通字段和审核字段分别保留修改代次，元信息放在节点内部，不重复保存参数值。
- 发布快照限定节点、连线和不可变审核结构。运行读取只叠加当前节点允许变更的字段；预览读取自己的快照。
- 专用参数接口执行事务、归属校验、代次校验。整份草稿保存对已发布节点保留服务端最新生效参数，避免旧页面覆盖。
- 审核脚本和步骤结构保持发布后不可变；参数、模型按原接口校验。审核任务在领取时使用最新允许参数，执行中采用已记录快照，完成结果不因普通字段变化而失效。
- 统一任务恢复与执行时的代次判断。模型占用检查改为读取节点及版本配置，凭据仍留在模型卡中。
- 私有答案、审核内部参数及服务端元信息不直接下发给学生；沿用并核对运行时序列化。

## 迁移与风险

先备份，再提交检查点，再改代码。迁移在事务中读取旧有效参数、合并节点、保留代次和修改人，核对后删除旧表。两表当前分别 2/7 条，普通覆盖 1 个节点，历史 versionOverrides 为 0；无活动审核任务。迁移仍检查旧数据的节点/步骤对应关系，无法无损对应时终止事务，不猜测。

历史 versionOverrides 如存在，须将其物化到对应版本的配置中，保存迁移前后审计证据并重算配置摘要；正式共享值仍优先。当前库不触发此分支。

需覆盖模型引用、复制、资源删除、账号清理、初始化及任务恢复路径。旧结构不可被新建库或重启重新创建。
