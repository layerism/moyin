# 学生节点操作区对齐设计

## 目标

调整学生节点弹窗底部“暂存/提交节点”操作区的对齐与视觉重量，使文件未上传时的辅助提示不再拉伸按钮，两个操作保持稳定的基线和清晰主次关系。

## 根因

`runtime-submit-control` 在提交按钮下方渲染“请先上传文件”提示；父级 Flex 容器默认 `align-items: stretch`，导致同级的“暂存”按钮被拉伸到提示区域的总高度，造成按钮厚重且上下不齐。

## 方案

- 操作行改为顶部对齐，提交按钮和暂存按钮均固定为 `40px` 高度；
- 提示文案保留在提交按钮下方，但不参与按钮高度计算；
- 暂存使用白底描边的次级按钮；提交使用收敛的蓝色主按钮、轻阴影和统一圆角；
- 禁用提交改为浅蓝灰背景与低对比文字，保留“请先上传文件”原因；
- 窄屏时保持右对齐和相同的上下结构，不改动动作顺序、按钮文案或提交逻辑。

## 验收标准

- 暂存与提交按钮的顶部、底部基线一致，均为 40px 高；
- 文件未上传时，辅助提示位于提交按钮下方，不再拉伸暂存按钮；
- 主按钮视觉明确但不过度厚重；
- 文件上传、暂存、提交和禁用规则保持不变。

## 验证边界

按项目约定仅执行 CSS 与 Git 范围静态审计，不运行自动化测试、构建或浏览器测试，由用户手动确认。
