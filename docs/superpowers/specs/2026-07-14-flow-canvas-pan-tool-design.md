# 流程画布手形平移工具设计

## 目标

在教师流程设计器的画布工具栏中增加手形工具，使用户能够拖动画布空白区域来平移当前视口。该功能只改变浏览位置，不修改节点坐标、连线关系或数据库数据，并且在流程发布冻结后仍然可用。

## 交互设计

- 工具栏增加带手形图标的切换按钮，并通过 `aria-pressed` 表达启用状态。
- 启用后，画布显示 `grab` 光标；按住画布空白区域时显示 `grabbing` 光标。
- 拖动时根据指针位移更新画布容器的 `scrollLeft` 与 `scrollTop`。
- 仅允许从画布空白区域开始平移；节点、连接点、连线和操作按钮继续执行各自原有行为。
- 再次点击手形按钮退出平移模式。

## 发布状态

发布后仍维持现有结构冻结规则：禁止新增节点、删除节点、配置节点、创建或删除连线以及自动布局。手形平移工具不属于结构编辑，因此保持可用。

## 实现边界

- 使用 React 状态、Pointer Events 和原生滚动容器实现，不引入第三方画布依赖。
- 平移状态仅存在于当前页面会话，不持久化视口位置。
- 本次不开放已发布流程中的节点拖动，也不修改后端接口。

## 验证

- 未启用手形工具时，画布交互保持不变。
- 启用后可从空白区域向任意方向平移，并正确显示抓取光标。
- 从节点或连线区域按下不会触发画布平移。
- 已发布流程仍可平移画布，但结构编辑继续不可用。
- 前端单元测试及生产构建通过。
