# 审核脚本配置字段对齐设计

## 目标

统一审核脚本配置表单中普通输入字段与布尔字段的视觉结构，消除“模型思考”大框与其他输入框尺寸不一致的问题。

## 交互与视觉结构

- 所有字段统一采用“标题、说明、控件”三层结构。
- 文本、数字和选择字段保持现有输入控件样式。
- 布尔字段不再使用包裹标题和说明的整块边框。
- 布尔字段的标题和说明移到控件框外，与其他字段一致。
- 布尔控件框与普通输入框等宽，最小高度统一为 `42px`，沿用相同边框和圆角。
- 布尔控件框内显示“启用”和复选框，整行可点击切换。
- 两列网格、字段顺序和响应式单列规则保持不变。

## 数据边界

- 不修改 JSON 配置结构。
- 不修改布尔值读取、校验和保存逻辑。
- 不修改其他字段类型的渲染逻辑。

## 验收标准

- “模型思考”的标题、说明和控件层级与相邻字段一致。
- 布尔控件框与同列普通输入框宽度、边框、圆角和高度一致。
- 点击“启用”控件行或复选框均可切换布尔值。
- 禁用状态继续阻止修改。

## 验证边界

按照项目规则，不运行自动化测试、不执行构建、不使用浏览器插件；仅进行静态结构审计、差异检查、服务重启和端口核对。
