# 删除“信息填写”组件入口设计

## 目标

从教务流程设计器左侧组件库中删除“信息填写（填写基础文本信息）”入口，其余组件入口保持不变。

## 实现范围

- 从 `nodeTemplates` 中删除标题为“信息填写”的模板项。
- 保留“表单填写”模板。
- 保留 `form` 节点类型及其创建、编辑、发布、学生填写和历史数据兼容逻辑。
- 不删除画布或已发布流程中现有的 `form` 节点。

## 方案

直接修改共享模板清单，不在组件渲染层增加按标题过滤逻辑。组件库继续统一从 `nodeTemplates` 渲染，避免配置与界面出现两套规则。

## 成功标准

- 左侧组件库不再显示“信息填写”。
- “表单填写”“文件上传”“确认承诺”“通知公告”及流程控制入口保持不变。
- 现有流程中的信息填写节点仍可显示和运行。
