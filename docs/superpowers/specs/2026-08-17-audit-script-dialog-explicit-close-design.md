# 审核脚本管理弹窗显式关闭设计

## 目标

审核脚本管理弹窗只能通过右上角 `×` 主动关闭，点击弹窗外部遮罩不触发退出。

## 实现边界

- 移除审核脚本管理遮罩层对 `onClose` 的点击绑定。
- 保留弹窗内容区域的事件隔离，不改变内部按钮行为。
- 保留右上角 `×` 的关闭行为；保存过程中继续禁用该按钮。
- 当前组件没有 `Escape` 关闭监听，无需新增或移除键盘逻辑。
- 不修改其他弹窗的遮罩行为。

## 验收标准

- 点击审核脚本管理弹窗外部时，弹窗保持打开。
- 点击右上角 `×` 时，弹窗关闭。
- 保存期间不能关闭弹窗。

## 验证边界

按照项目规则，不运行自动化测试、不执行构建、不使用浏览器插件；仅进行静态调用链审计、差异检查、服务重启和端口核对。
