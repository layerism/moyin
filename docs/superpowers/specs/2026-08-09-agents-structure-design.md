# AGENTS.md 结构整理设计

## 目标

将根目录 `AGENTS.md` 整理为一个一级总标题和按职责划分的二级章节，使标题层级一致、规则归属明确，同时保持现有开发约束。

## 标题结构

唯一一级标题为 `# 项目开发规范`，其下依次设置：

1. `## 工具与需求确认`
2. `## 版本管理与协作`
3. `## Node.js 运行环境`
4. `## 开发文档`
5. `## 验证约束`
6. `## 服务管理`
7. `## 开发清理`

## 内容归属

- Superpowers、build-web-app、Ponytail、逻辑检查和需求确认归入“工具与需求确认”。
- 当前分支、前后检查点提交和 subagent 数量限制归入“版本管理与协作”。
- 固定 Node.js/npm 版本及 PATH 命令归入“Node.js 运行环境”。
- `docs/superpowers` 文档要求归入“开发文档”。
- 禁止开发中测试和浏览器、仅做业务逻辑审计归入“验证约束”。
- 本地非 Docker 重启要求归入“服务管理”。
- 缓存清理要求归入“开发清理”。

## 内容修正

- 将“小改动不要写文档”明确为“小改动不编写额外专题文档，但仍需遵守 `docs/superpowers` 开发文档要求”，消除与强制开发文档规则的冲突。
- 将缓存目录名称规范为 `.pytest_cache`、`__pycache__` 和 `*.egg-info`。
- 统一工具名称与标点，不降低任何原有约束强度。

## 验收

- 文件仅包含一个一级标题。
- 所有规则位于语义对应的二级章节下。
- Node.js `24.18.0`、npm `11.16.0` 和 `.local/node` 约定保持不变。
- 不新增脚本、依赖或测试；仅进行 Markdown 结构与规则一致性审计。
