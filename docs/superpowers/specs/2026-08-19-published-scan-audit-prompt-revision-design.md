# 发布后扫描审核提示词修订设计

## 目标

教师进入已发布流程的修订模式后，允许修改既有确认节点的 AI 扫描审核提示词，即界面中的“评分标准”或“形式审核标准”。

## 业务规则

- 仅放开 `scanAuditPrompt`，审核开关、审核模式、模板和其他审核配置仍保持锁定。
- 修改保存在修订草稿中，不覆盖当前发布版本，也不改变正在执行的历史审核任务。
- 教师重新发布后，新提示词写入新的不可变流程版本。
- `scanAuditPrompt` 继续作为节点业务字段参与修订影响分析；提示词变化会使该节点及其可达下游节点重新完成。
- 未发布流程和新增节点保持现有完整编辑能力。

## 实现范围

- 前端发布后旧节点允许字段增加 `scanAuditPrompt`。
- 后端发布后修订校验白名单增加 `scanAuditPrompt`，保证服务端规则与界面一致。
- 更新修订提示文案，明确提示词可修改及其影响。
- 增加前端允许字段和后端修订接口行为用例。

## 验证边界

遵循项目开发规范，本次只编写测试并进行静态业务逻辑审计，不执行测试、构建或浏览器检查。完成后以本地非 Docker 方式重启前后端服务。
