# 节点设置弹窗背景锁定设计

## 目标

教师点击流程节点的设置按钮并打开“节点设置”弹窗后，背景页面与流程画布保持完全锁定。用户只能通过右上角“×”或底部“完成”关闭弹窗。

## 现状与根因

1. 遮罩层当前直接绑定关闭回调，因此点击弹窗外的背景会关闭弹窗。
2. 弹窗打开期间未锁定页面滚动；在遮罩区域滚动，或弹窗内容滚动到边界后继续滚动，会带动背景页面或画布。

## 交互规则

1. 点击节点设置按钮后打开现有“节点设置”弹窗。
2. 弹窗打开期间，背景页面和流程画布不能被点击、拖动、滚动或缩放。
3. 点击遮罩层不关闭弹窗，也不改变弹窗状态。
4. 弹窗内部表单、按钮和内容滚动保持可用。
5. 弹窗内容滚动到顶部或底部后，继续滚动不得传递到背景页面。
6. 仅右上角“×”和底部“完成”调用现有关闭回调；不新增 Escape 或其他关闭入口。
7. 弹窗关闭后，恢复打开前的页面滚动状态。

## 实现方案

1. 移除节点设置遮罩层上的关闭事件，只保留两个显式关闭按钮。
2. 在 `NodeInspector` 挂载期间锁定页面滚动，并在组件卸载时恢复原有状态，避免影响弹窗关闭后的页面行为。
3. 对弹窗可滚动内容区设置滚动边界隔离，防止滚动链传递到背景。
4. 复用现有组件、样式和关闭回调，不新增依赖、通用弹窗抽象或后端逻辑。

## 影响范围

- 修改教师端节点设置弹窗及其局部样式。
- 不修改学生端节点填写弹窗、其他确认弹窗、后端接口、数据库或流程数据结构。

## 验收标准

1. 打开节点设置后，在遮罩任意位置点击，弹窗保持打开。
2. 在遮罩上使用鼠标滚轮或触控板，背景页面和画布位置保持不变。
3. 在弹窗内部滚动时，仅弹窗内容移动；到达滚动边界后背景仍不移动。
4. 弹窗打开期间，背景节点不能选中、拖动或触发画布缩放。
5. 点击右上角“×”或底部“完成”均可关闭弹窗。
6. 关闭弹窗后，页面和画布恢复原有交互。

## 验证边界

按项目约定，开发过程仅进行源码与业务逻辑审计，不运行自动化测试、构建或 Browser；完成后由用户手动验证上述交互。
