# 节点描述按需展示设计

## 目标

流程概览卡片不直接显示节点描述。教师或学生打开节点后，才在现有详情界面中查看完整描述。

## 教师端

- 流程画布节点只显示标题、节点类型和状态，不显示描述。
- 教师继续通过双击节点或点击齿轮打开节点设置。
- 节点设置中的描述编辑框保持不变，完整描述可查看和编辑。
- 教师端学生预览卡片同样不显示描述。

## 学生端

- 学生流程图节点只显示标题、节点类型和状态，不显示描述。
- 学生继续通过单击可办理节点打开办理弹窗。
- 办理弹窗标题下方继续显示完整节点描述。

## 排版与兼容性

- 描述字段继续保存在流程节点数据中，不修改接口、数据库或历史数据。
- 节点宽度保持固定，高度只随标题换行变化。
- 现有 `ResizeObserver` 高度测量、连接点和连线同步逻辑保持不变。
- 删除只服务于概览描述的卡片样式，不影响弹窗描述样式。

## 验收标准

1. 教师画布、学生流程图及教师端学生预览卡片均不显示节点描述。
2. 教师打开节点设置后仍可查看和编辑描述。
3. 学生打开办理弹窗后仍可查看完整描述。
4. 节点标题、类型、状态和连线布局保持正常。
