# 教师端节点填写数据 Excel 导出设计

> 状态：方案已确认。本设计增加节点级填写数据导出，不改变学生提交、审核或流程推进规则。

## 目标

教师在“学生填写进度”面板中选择任一发布节点并导出 Excel。导出以当前有效名单为行集合，因此尚未进入流程或尚未提交该节点的学生也必须保留一行；姓名、学号以外的提交字段使用空单元格。

## 交互

- 在现有批量材料下载区旁增加“节点填写数据”选择器和“导出 Excel”按钮。
- 选择器按发布快照的节点顺序列出全部节点，不增加主进度表的横向列。
- 导出期间按钮显示“正在导出…”，并禁止重复点击。
- Excel 文件名为“流程名称-节点名称-填写数据.xlsx”。

## 数据范围

- 行集合来自流程当前 `active` 名单，不从运行实例反推，排除已撤销名单和教师预览身份。
- 每名学生只读取所选发布版本、所选节点的当前有效提交，即提交 `attempt_no` 与节点实例当前 `attempt_no` 一致。
- 不导出草稿、历史提交、已失效提交或流程修订前的审计快照。
- 没有当前提交时，只写序号、学号和姓名；所有提交及审核字段保持为空。
- 节点定义来自不可变的 `flow_versions.config_snapshot`，表单列按发布时字段顺序生成。

## Excel 列

所有节点固定前三列为“序号、学号、姓名”，之后按节点类型追加：

- 通用提交列：提交状态、提交时间；
- 表单节点：每个表单字段一列；单选写选项名称，多选用中文分号连接，多行文本保留换行；
- 文件节点：文件名、文件大小（MB）、文件类型；
- 公告节点：是否确认；
- 确认节点：是否确认；存在模板时再写模板下载时间、扫描件数量、扫描件名称、扫描件页数；
- 有审核结果时：审核状态、审核方式、审核结论或分数、审核说明。

技术字段如内部 ID、OSS 对象键、哈希和审核参数不进入 Excel。学号按文本格式写入，表头冻结并开启筛选，内容列自动换行。

## 实施范围

- 新增后端节点导出查询与工作簿生成服务；使用项目现有 `openpyxl`，不新增依赖或数据库迁移。
- `backend/app/api/routes/workflow_admin.py` 增加教师鉴权的节点导出接口。
- `frontend/src/features/academic-flow/api.ts` 增加下载调用。
- `frontend/src/features/academic-flow/TeacherProgressPanel.tsx` 增加节点选择及导出状态。
- `frontend/src/styles.css` 只补充现有工具栏所需的紧凑布局，不引入新的视觉体系。
