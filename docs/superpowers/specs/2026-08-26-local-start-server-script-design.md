# 本地服务启动脚本设计

## 目标

在项目根目录提供 `start_server.sh`，用一条命令同时启动 Moyin 前端与后端，并在终止脚本时清理两个子进程。

## 启动约定

- 后端从 `backend/` 启动，使用 `backend/.venv`，监听 `127.0.0.1:8000`。
- 前端从 `frontend/` 启动，优先使用项目 `.local/node/bin`，通过现有 `npm run dev` 监听 `0.0.0.0:5173`。
- 脚本可从任意工作目录调用；日志直接输出到当前终端。
- 收到 `INT` 或 `TERM` 时，脚本终止本次启动的前后端进程并等待其退出。

## 范围与验证

只新增设计文件和根目录启动脚本，不修改业务代码、README 或 Docker 配置。完成后使用该脚本重启本地服务，并通过进程参数与 5173、8000 端口监听状态进行核对；不运行测试或浏览器自动化。
