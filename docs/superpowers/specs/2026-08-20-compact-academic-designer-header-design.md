# 教务流程设计器紧凑页头设计

> 状态：方案已确认。本设计只压缩教师流程设计器顶部信息区，不改变按钮行为、权限状态或后端接口。

## 目标

减少独立品牌页头、面包屑和流程信息分层占用的纵向空间，使组件库与流程画布整体上移，同时保留当前所有操作入口及流程状态。

## 布局

- 将教师设计器的面包屑并入独立品牌页头，形成“返回、品牌、当前位置”一行。
- 将流程名称、发布状态和流程说明合并为单行摘要；说明超长时省略显示，并通过 `title` 提供全文。
- 保留“学生名单、预览、学生链接、进度、暂存、发布或解锁编辑”等全部按钮，宽屏时与摘要同排。
- 将设计器品牌页头压缩至约 48px，并缩小顶部工作区内边距及信息区下边距。
- 窄屏允许摘要和操作区换行，不隐藏功能，也不把操作收纳进额外菜单。

## 实施范围

- `frontend/src/features/academic-flow/AcademicFlowDesigner.tsx`：为教师设计器页头传入当前位置，并将流程信息调整为紧凑摘要结构。
- `frontend/src/styles.css`：增加教师设计器专用页头、摘要及响应式样式。

学生填写页继续使用原有页头和面包屑结构；不修改流程数据、保存、预览、发布、名单或进度相关逻辑。

## 验证边界

依项目规范仅做静态审计，检查原按钮渲染条件、禁用条件、事件处理和移动端换行规则均保持不变。修改过程中不运行自动测试、构建或浏览器检查。
