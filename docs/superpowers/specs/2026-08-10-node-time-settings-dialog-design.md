# 节点定时设置二级弹窗设计

## 目标

将所有节点共用的定时设置由节点弹窗内联展开改为二级弹窗编辑。时间修改先保存在本地草稿中，只有明确确认后才写入节点。

## 入口与层级

- 节点设置主弹窗继续显示“＋ 定时设置”按钮和已配置时间的状态摘要。
- 点击按钮后，在节点设置弹窗上方打开居中的二级弹窗。
- 二级弹窗具有独立遮罩和更高层级，但不关闭底层节点设置弹窗。
- 所有使用共享节点设置弹窗的节点统一使用该入口。

## 时间编辑内容

- 弹窗标题为“定时设置”。
- 内容包含起始时间、截止时间、各自清除操作和开放时长说明。
- 继续复用现有 `NodeDateTimePicker`，不增加重复计划或新的时间字段。

## 草稿与提交

- 打开弹窗时，将当前节点的 `startAt`、`deadlineAt` 复制为本地时间草稿。
- 日期选择和清除操作只修改本地草稿，不即时调用节点更新。
- 点击“确定”后，通过一次 `onUpdateNode(node.id, { startAt, deadlineAt })` 写入两个字段并关闭弹窗。
- 点击“取消”、右上角关闭、时间弹窗遮罩或按 Escape 时，关闭二级弹窗并丢弃本次时间草稿。
- 关闭二级弹窗不会关闭底层节点设置弹窗。

## 校验

- 当起始时间和截止时间同时存在且起始时间不早于截止时间时，显示“起始时间必须早于截止时间”。
- 时间顺序无效时禁用“确定”，防止将已知无效配置写入节点。
- 单独设置起始时间、单独设置截止时间或同时清空均允许确认，保持现有业务规则。

## 兼容性与边界

- 不修改数据库、后端接口、节点类型或时间字段格式。
- 不改变标题、说明和各节点专属设置。
- 不增加周期重复、填写名单或结束页功能。
- 不增加第三方依赖。

## 验收标准

1. 所有节点点击“定时设置”均打开二级时间弹窗，主弹窗不再内联展开时间区域。
2. 取消、关闭、遮罩和 Escape 均不保存时间修改。
3. 点击“确定”同时写入起始时间和截止时间。
4. 无效时间顺序显示错误并禁止确认。
5. 确认后主弹窗状态摘要反映最新配置。
