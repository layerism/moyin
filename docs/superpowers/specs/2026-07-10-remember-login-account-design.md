# 登录账号记忆设计

## 目标

降低教师和学生重复输入姓名、工号或学号的成本，同时保持密码与会话凭据的安全边界。

## 设计

- 登录页提供默认勾选的“记住账号”复选框。
- 仅在登录成功后保存当前角色、姓名和工号/学号；不保存失败或未提交的输入。
- 教师和学生账号分别保存，切换身份时恢复对应数据。
- 取消勾选并成功登录后，清除当前角色的已记忆账号。
- 注册页不读取或写入账号记忆。
- 密码、Cookie、Session ID 和 Token 不写入 Web Storage；密码继续由浏览器密码管理器处理。
- 本地存储使用版本化键 `oa.auth.remembered.v1`，无效或旧格式数据按空状态处理。

## 表单规范

- 表单和输入框提供稳定的 `id`、`name`、`required` 与正确的 `autocomplete`。
- 工号/学号使用 `autocomplete="username"`。
- 登录密码使用 `autocomplete="current-password"`，注册密码使用 `autocomplete="new-password"`。

## 验证

- 单元测试覆盖角色隔离、损坏数据容错、保存和清除。
- 浏览器验证默认勾选、成功登录后回填、身份切换隔离以及密码不进入本地存储。
- 运行前端测试和生产构建。
