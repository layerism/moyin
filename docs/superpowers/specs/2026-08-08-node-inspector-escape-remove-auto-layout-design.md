# 节点设置 Esc 关闭与移除自动布局设计

## 目标

完善教务流程设计器的键盘关闭行为，并删除不再需要的自动布局功能：

1. 节点设置面板支持按 `Esc` 关闭。
2. 流程画布不再提供自动布局能力。

## 节点设置关闭规则

- `Esc` 与右上角 `×`、底部“完成”共用现有 `onClose` 回调。
- 关闭仅隐藏节点设置面板，不回滚已经写入当前工作草稿的字段修改。
- 在 `NodeInspector` 生命周期内注册窗口级 `keydown` 监听，确保焦点仍停留在画布或位于面板控件中时均能响应。
- 面板卸载时移除监听，避免重复注册或影响其他页面。
- 日期时间选择器继续优先处理并阻止其内部 `Esc` 事件，但将现有仅吞掉事件的分支补全为调用 `closePicker()`：第一次 `Esc` 只关闭选择器且不改变日期值，随后再次按 `Esc` 才关闭节点设置面板。

## 自动布局删除范围

完整删除自动布局功能，而不只隐藏按钮：

- 删除画布工具栏中的“自动布局”按钮，保留缩放百分比显示。
- 删除 `AcademicFlowDesigner` 中的 `autoLayoutNodes` 回调和 `layoutRevisionNodes` 导入。
- 删除 `FlowNodeCanvas` 的 `onAutoLayout` 属性及局部 `autoLayout` 包装函数。
- 删除失去调用方的 `layoutRevisionNodes` 工具函数、仅供该函数使用的类型，以及对应专属测试。

节点的手动拖动、已发布节点位置锁定、画布缩放和平移均保持原逻辑。

## 实现边界

- 前端内部修改，不新增组件、状态、样式、依赖、接口、数据库字段或后端逻辑。
- 不改变节点字段的实时工作草稿更新机制。
- 不改变其他弹窗或连线删除快捷键。日期时间选择器仅补全 `Esc` 关闭自身的标准行为。

## 验证边界

按项目约定不运行自动化测试、构建或浏览器测试，只进行静态差异与调用链审计。用户手动验证：

1. 节点设置打开时按 `Esc` 与点击 `×` 的结果一致。
2. 修改字段后按 `Esc`，重新打开面板仍能看到当前工作草稿中的修改。
3. 日期时间选择器打开时，第一次 `Esc` 只关闭选择器。
4. 画布不再显示“自动布局”，缩放、平移和节点拖动保持正常。
