# 数据库管理页固定视口滚动设计

## 目标

数据库管理页在桌面端始终占满一个视口，页面本身不出现纵向滚动条。左侧数据表导航只展示可用高度内的条目，超出后在左侧区域内独立滚动。

## 布局

- `.database-admin-page` 使用两行 Grid：顶部栏自然高度，主体占据剩余高度；页面高度固定为 `100dvh` 并隐藏自身溢出。
- `.database-admin-layout` 使用 `min-height: 0` 和 `overflow: hidden`，防止内容撑高 Grid 行。
- `.database-table-nav` 保持导航标题与表列表为同一滚动区，使用 `overflow-y: auto`。
- `.database-table-main` 使用纵向 Flex；工具栏和分页保持可见，数据表格占用剩余高度并在自身内滚动。

## 响应式边界

760 px 以下保留现有单列布局：数据表导航改为顶部横向滚动，右侧数据区继续占用剩余高度。

## 验收标准

1. 桌面端页面不产生浏览器纵向滚动。
2. 左侧 20 个数据表不再全部撑开页面，左侧可独立滚动。
3. 右侧工具栏与分页保持在视口中，超高数据在表格内滚动。
4. 不修改数据请求、表选择、编辑、删除或分页逻辑。
