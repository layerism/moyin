# 全部节点基础设置样式重构设计

## 目标

将所有可编辑流程节点的基础设置区统一改为参考图中的轻量问卷式布局。只调整标题、描述和时间设置的展示与交互，不改变节点数据结构及各类节点的专属业务配置。

## 适用范围

- 表单填写、文件上传、确认承诺、通知公告、条件分支、并行节点等所有使用节点设置弹窗的节点。
- 各节点原有的表单字段、文件限制、扫描审核、承诺内容、分支条件等专属配置继续显示在基础设置区下方。
- 不增加“填写名单”“结束页”或周期重复功能。

## 基础设置布局

- 保留弹窗外壳、遮罩、右上角关闭按钮和底部完成操作。
- 移除顶部重复显示的“节点设置”、节点名称和节点类型徽标。
- 弹窗内容顶部直接显示大号、无边框标题输入框；空值占位为“请添加标题”。
- 标题下方显示轻量描述输入区；空值占位为“添加描述”。本次不增加图片或链接编辑能力。
- 发布后修订提示继续保留，并排列在基础设置区与节点专属配置之间。

## 时间设置

- 基础设置区仅显示“＋ 定时设置”按钮。
- 点击按钮展开现有起始时间、截止时间和开放时长说明；再次点击折叠。
- 展开区域使用白色背景、浅色边框和紧凑间距，移除深色标题栏、粗边框及厚重阴影。
- 已配置任一时间时，按钮旁显示简洁状态摘要，且重新打开弹窗时默认展开，避免隐藏已有配置。
- 继续复用现有 `startAt`、`deadlineAt`、时间选择器、清除操作和时间校验逻辑。
- 不新增周期、重复规则或后端字段。

## 兼容性与边界

- 不新增依赖，不修改数据库、后端接口或节点类型定义。
- 不改变节点标题、说明、起止时间的保存方式。
- 不改变各节点专属配置的能力、顺序和校验规则。
- 发布后修订锁定规则及修改影响提示保持不变。

## 验收标准

1. 所有可编辑节点均使用统一的大标题、轻量描述和“定时设置”入口。
2. 空标题和空描述分别显示“请添加标题”“添加描述”。
3. 时间设置可以展开和折叠，已有时间的节点重新打开时默认展开。
4. 展开区域保留起始时间、截止时间、清除操作和开放时长说明。
5. 界面中不存在“填写名单”“结束页”或重复设置功能。
6. 各节点原有专属配置及数据协议保持不变。
