# 答题卡题目二级编辑弹窗设计

> 状态：已批准并完成实现。

## 目标

答题卡主体只显示紧凑题目列表。点击题目摘要后打开二级弹窗，在弹窗内编辑题干、分值、必答设置、选项、正确答案或填空标准答案，避免多题在同一长列表中展开。

## 交互规则

- 点击题目摘要打开二级弹窗；题目不再行内展开。
- 题目弹窗使用本地临时草稿，不在输入过程中写回答题卡。
- 点击“确认”一次性保存公开题目与私有标准答案并关闭。
- 题目不完整时仍允许确认；外层题目摘要继续显示“需修正”，最终完成答题卡配置时沿用现有统一校验。
- 点击“退出”或右上角“×”放弃本次草稿。
- 点击遮罩或按 `Escape` 不关闭题目弹窗。
- 新增题目先创建临时草稿并立即打开弹窗；退出时不创建题目，确认后才插入题目和私有答案。
- 拖拽手柄只负责排序；“…”菜单只负责移动和删除，不触发题目弹窗。
- 编辑锁定时仍允许打开弹窗查看题目，但只提供“退出”操作。

## 状态边界

弹窗草稿包含且仅包含一对相同题号的数据：

```ts
type AnswerSheetQuestionDraft = {
  answer: AnswerSheetPrivateAnswer;
  isNew: boolean;
  question: AnswerSheetQuestion;
};
```

选择题选项、正确答案、旧版多空结构及新版单 Markdown 填空均继续复用现有编辑组件。保存时调用一次现有 `onChange(config, gradingKey)`，不修改答题卡数据协议、校验规则或自动判分规则。

## 弹窗结构

```text
┌ 编辑第 N 题 ───────────────────── × ┐
│ 分值                           必答 │
│ 题干 Markdown                       │
│ 选项与正确答案 / 标准答案           │
│ 当前题目的校验信息                  │
├─────────────────────────────────────┤
│                         退出  确认  │
└─────────────────────────────────────┘
```

弹窗覆盖节点设置弹窗，内容区独立滚动；页头和页脚固定可见。遮罩仅建立视觉层级，不绑定关闭行为。

## 影响范围

- `frontend/src/features/academic-flow/AnswerSheetEditor.tsx`
- `frontend/src/styles.css`
- 删除不再使用的行内展开状态辅助函数；保留排序、校验、题型编辑器和数据契约。

## 验收标准

1. 外层题目列表始终保持单行摘要，不出现行内题目编辑区。
2. 已有题目的修改仅在确认后写回；退出后原数据不变。
3. 新增题目退出后题目数不变，确认后新增一题。
4. 不完整题目可以确认，外层显示“需修正”。
5. 遮罩和 `Escape` 不关闭弹窗；退出、右上角“×”和确认可以关闭。
6. 排序手柄与题目“…”菜单保持原行为且不会打开弹窗。
7. 单选、多选、新版单 Markdown 填空和旧版填空均复用现有字段与判分语义。
