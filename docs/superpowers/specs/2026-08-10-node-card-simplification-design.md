# 节点卡片精简与模板文案设计

## 目标

移除所有流程概览卡片的节点编号，将标题限制为最多两行，并把扫描审核相关的“承诺书模板”统一命名为“签署文件模板”。

## 节点编号

- 教师流程画布节点不显示编号或圆形编号标记。
- 学生流程图节点不显示编号或圆形编号标记。
- 教师端学生预览卡片不显示编号或圆形编号标记。
- 删除编号后同步移除对应网格列、左侧留白和无用样式。
- 节点顺序、流程关系、数据库数据和连接逻辑不依赖显示编号，均保持不变。

## 节点标题

- 教师流程画布、学生流程图和教师端学生预览卡片的标题最多显示两行。
- 超过两行的内容使用多行省略号截断。
- 标题字号沿用各入口现有字号，不因标题长度缩小。
- 完整标题继续保存在节点数据中，可在教师节点设置或学生办理弹窗中查看。
- 教师画布继续保留固定宽度和 `ResizeObserver` 高度同步机制。

## 模板文案

以下用户可见文案统一使用“签署文件模板”：

- `签署文件模板（DOCX）`
- `下载签署文件模板`
- `请先下载签署文件模板`
- 发布校验中的 `DOCX 签署文件模板`

“替换模板”“删除模板”“下载模板”“重新下载”等通用操作文案保持不变。模板文件类型、资源数据、上传下载接口和扫描审核逻辑均不修改。

## 边界与兼容性

- 不新增依赖，不修改后端、数据库或流程节点数据结构。
- 不改变节点点击、双击、拖拽、连线、状态和权限逻辑。
- 不改变教师节点设置或学生办理弹窗中的完整标题和描述。
- 按项目约束只进行静态业务逻辑审计，不运行测试、构建或浏览器自动化。

## 验收标准

1. 三类流程概览卡片均无节点编号及其占位空间。
2. 三类卡片标题最多显示两行，超出后出现省略号。
3. 扫描审核相关界面和校验信息均不再出现“承诺书模板”。
4. 打开节点后仍可查看完整标题和描述。
5. 模板上传下载、节点连线和流程数据保持不变。
