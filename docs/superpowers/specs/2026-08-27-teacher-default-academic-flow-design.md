# 教师登录默认进入教务流程设计

> 状态：方案已确认。本设计只调整教师登录后的默认落点和教师侧栏入口，不改变学生端、流程数据或后端接口。

## 目标

- 教师登录成功后直接进入教务流程列表，并在侧栏中显示“教务流程”为选中状态。
- 删除教师首页与教务流程列表侧栏中的“首页”入口，避免保留不再需要的导航标签。

## 行为边界

- 教师认证成功后导航到 `/academic-flow`；学生认证成功后的 `/student` 路径保持不变。
- “OSS 云盘”仍可进入原首页文件区，教务流程列表中的页面面包屑继续保留“首页 › 教务流程”。
- 管理员数据库页、流程设计器返回、学生运行页和旧材料收集工作区的返回逻辑不变。

## 实施范围

- `frontend/src/App.tsx`：将教师认证完成后的默认导航由首页改为教务流程列表，并移除不再使用的 `onHome` 属性传递。
- `frontend/src/features/home/HomeView.tsx`：删除两个教师侧栏中的“首页”按钮及教务流程列表不再需要的 `onHome` 属性。

## 验证边界

依项目规范不运行测试、构建或浏览器检查。仅通过代码差异、引用搜索和 TypeScript 属性调用链进行静态审计；完成后重启本地服务并核对监听端口和进程工作目录。
