# 流程连线层动态高度修复设计

## 问题

流程节点可以位于逻辑坐标 `y > 1000`，画布外层也会按节点位置动态增高；但 SVG 连线层与其内容容器仍固定为 `1000px` 高。节点和 HTML 形式的连线删除按钮因此可以显示，跨越 SVG 下边界的连线路径却会被裁剪。

## 设计

- 继续以现有 `canvasSurfaceHeight` 作为画布逻辑高度的唯一来源。
- 将该高度同时赋给画布内容容器和 SVG 连线层。
- 保留现有节点、端口、正交路径和删除按钮计算，不改变流程数据结构。
- 不使用固定大高度或 `overflow: visible` 绕过边界，以免再次出现坐标层尺寸不一致。

## 验收标准

- 逻辑坐标超过 `1000` 的节点之间能显示完整连线。
- 连线、箭头、命中区域和删除按钮仍使用同一组逻辑坐标。
- 空画布继续保持至少 `1000px` 的逻辑高度。
- 不影响缩放、节点拖动和多选功能。

## 验证方式

按照项目约束，不运行测试或浏览器验证；通过代码审计确认所有画布层共享 `canvasSurfaceHeight`，并检查修改范围仅涉及画布尺寸传递。
