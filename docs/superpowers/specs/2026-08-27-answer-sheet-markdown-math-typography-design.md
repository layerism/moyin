# 答题卡 Markdown 与数学公式排版设计

## 目标

统一答题卡题干、选项中的 Markdown 与 KaTeX 视觉尺度，避免标题和公式相对正文过大，同时保持教师编辑页、教师学生预览和正式学生端的语义一致。

## 已确认方案

- 保留现有 `react-markdown`、`remark-math`、`rehype-katex` 解析链路，不改变 Markdown 语法与内容数据。
- 仅在答题卡 CSS 中建立排版标尺，不增加字号设置项，不使用 `transform: scale()`。
- 题干正文使用 15px 基础字号，选项正文使用 14px 紧凑字号。
- 一级、二级标题改用相对字号；选项中的标题按局部强调文字处理，避免形成页面级标题。
- 行内公式覆盖 KaTeX 默认的 `1.21em`，调整为 `1.05em`；独立公式为 `1.1em`，并缩小上下间距。
- 独立公式在题干中居中，在选项中左对齐；超长公式横向滚动，不强制压缩。
- 编辑态与渲染态使用相同的基础文字尺度，减少失焦切换时的尺寸跳变。

## 影响范围

- 仅修改 `frontend/src/styles.css` 中答题卡 Markdown、编辑框和学生运行页相关样式。
- 不修改组件接口、后端接口、答题卡配置、发布快照或自动判分逻辑。

## 静态检查

- 确认样式只作用于 `.answer-sheet-markdown` 及其答题卡上下文。
- 核对题干、编辑器选项、学生端选项三类上下文使用一致的排版变量。
- 核对长公式具有横向滚动能力，且没有全局覆盖 KaTeX。

按项目约定，本次修改不运行测试和浏览器检查。
