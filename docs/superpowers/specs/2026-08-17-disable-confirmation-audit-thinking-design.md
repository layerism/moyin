# 关闭确认承诺图片审核模型思考设计

## 目标

确认承诺节点调用视觉模型审核扫描件时，显式关闭模型思考，避免供应商默认开启深度思考。

## 已确认决策

- 直接修改内部审核脚本 `confirmation-visual-audit` 的 `v1`，不新增脚本版本。
- 请求体增加 `"thinking": {"type": "disabled"}`。
- 模型、接口、提示词、温度、JSON 输出格式及响应解析逻辑保持不变。
- 不增加环境变量或教师端开关，确认承诺图片审核统一关闭思考。

## 版本影响

修改后 `v1` 文件哈希会变化。旧流程快照或已经打开的预览仍保存旧哈希，不能继续解析修改后的脚本；需要重新发布流程或重新打开预览，使运行时快照绑定新哈希。

## 验证边界

项目规范禁止在修改过程中运行测试、构建或浏览器检查。本次仅检查请求体结构、变更差异与 Python 静态语法，不向模型服务发起真实审核请求。
