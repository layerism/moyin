# 已发布节点资料包下载

> 状态：交互与业务范围已确认。

## 目标

教师在流程发布后，可直接右键画布中的已发布节点，下载该节点的综合资料包。资料包同时包含节点 Excel 汇总和全部学生当前有效提交中的文件，不增加画布常驻按钮，也不改变学生进度面板中的独立导出入口。

## 交互

1. 已进入当前发布版本的节点支持右键菜单，菜单标题显示节点名称，唯一操作为“下载节点资料包”，副文案为“Excel + 全部学生文件”。
2. 修订中的既有节点仍下载当前发布版本快照；尚未重新发布的新增节点显示禁用项“重新发布后可下载”。未发布流程不提供下载菜单。
3. 点击下载后关闭菜单，并在画布右上角显示紧凑的“正在打包 · 节点名称”状态；浏览器开始下载后自动移除，不显示成功提示。
4. 下载失败时显示红色错误反馈。点击空白区域或按 `Escape` 关闭菜单；节点支持 `Shift + F10` 或菜单键打开同一菜单。

## 压缩包契约

压缩包命名：`流程名称-节点名称-节点资料包.zip`。

```text
流程名称-节点名称-节点资料包.zip
├── 流程名称-节点名称-填写数据.xlsx
└── 学生文件/
    └── 学号-姓名/
        └── 学生原始文件
```

- Excel 始终生成，并继续包含当前有效名单中的全部学生；未提交学生的业务字段为空。
- 文件只取该节点当前有效尝试中的 `reviewing`、`approved`、`rejected` 或 `audit_error` 提交，与现有节点导出范围一致，不混入历史尝试。
- 没有文件的学生不创建空目录；没有任何学生文件时，压缩包只包含 Excel。
- 同一学生目录内的重名文件追加 `(2)`、`(3)`，不覆盖已有内容。
- 教师身份、发布版本归属和节点归属全部由服务端校验。

## 实施范围

- 后端新增发布版本节点资料包下载接口，复用节点 Excel 查询、工作簿生成和当前节点材料查询。
- 压缩包服务写入 Excel，并按“学生文件/学号-姓名”组织 OSS 文件。
- 前端 API 增加综合资料包下载调用；流程画布增加受发布状态约束的节点右键菜单与下载状态。
- 样式沿用现有白色面板、灰色边框、蓝色主操作和红色错误语义。
