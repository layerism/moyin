# 已发布节点资料包下载

> 状态：原始直接下载方案；交互已由 `2026-08-22-canvas-context-menu-and-filtered-download.md` 取代，压缩包基础契约继续有效。

## 目标

教师在流程发布后，可选中画布中的已发布节点，通过节点右侧操作栏下载该节点的综合资料包。资料包同时包含节点 Excel 汇总和全部学生当前有效提交中的文件，不改变学生进度面板中的独立导出入口。

## 交互

1. 选中已进入当前发布版本的节点后，在节点右侧现有操作栏显示下载按钮，尺寸和位置与设置按钮一致，悬停文案为“下载节点资料包”。
2. 正常发布态只显示下载按钮；发布后修订时，既有节点显示设置、下载和锁定标识，尚未重新发布的新增节点只显示原有设置与删除操作。
3. 点击下载按钮后直接开始打包；按钮切换为旋转状态并禁用重复点击，画布右上角同步显示“正在打包 · 节点名称”。浏览器开始下载后自动移除状态，不显示成功提示。
4. 下载失败时显示红色错误反馈。右键继续保留为画布拖动操作，不承担节点下载功能。

## 压缩包契约

压缩包命名：`流程名称-节点名称-节点资料包.zip`。

```text
流程名称-节点名称-节点资料包.zip
├── 流程名称-节点名称-填写数据.xlsx
└── 学生文件/
    └── 学号-姓名/
        └── 学生原始文件
```

- Excel 始终生成，并继续包含当前有效名单中的全部学生；未提交学生的业务字段为空。
- 文件只取该节点当前有效尝试中的 `reviewing`、`approved`、`rejected` 或 `audit_error` 提交，与现有节点导出范围一致，不混入历史尝试。
- 没有文件的学生不创建空目录；没有任何学生文件时，压缩包只包含 Excel。
- 同一学生目录内的重名文件追加 `(2)`、`(3)`，不覆盖已有内容。
- 教师身份、发布版本归属和节点归属全部由服务端校验。

- 样式沿用现有白色面板、灰色边框、蓝色主操作和红色错误语义。
