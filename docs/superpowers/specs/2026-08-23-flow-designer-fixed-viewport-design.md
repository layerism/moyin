# 流程设计器固定视口布局

> 状态：方案已确认。本设计只约束教师流程设计器的外层页面滚动，不改变流程数据、画布坐标、交互手势或其他页面。

## 目标

教师流程设计器始终限制在浏览器可视高度内。无论节点数量、坐标范围或画布内部高度如何增长，均不得撑高外层页面并产生整页滚动条。

## 布局边界

- 教师设计器根页面使用 `100dvh` 固定视口高度并隐藏外层溢出；保留 `100vh` 作为兼容回退。
- 独立页头保持自然高度且不可压缩，工作区占据剩余高度。
- 流程摘要、操作按钮和错误提示保持自然高度；流程网格占据工作区剩余高度。
- 组件库和画布面板允许沿高度链收缩，避免内部最小高度反向撑开父级。
- 画布视口填满画布面板剩余空间并保持 `overflow: hidden`；节点坐标范围只扩大变换层，通过既有平移与缩放查看，不产生画布滚动条。
- 组件库内容超出可用高度时，仅组件库内部纵向滚动。
- 窄屏继续采用单列布局，但组件库使用受限高度并内部滚动，画布占据其余空间；外层页面仍不滚动。
- 设置、下载等弹窗继续使用独立固定遮罩及内部滚动，不受设计器外层溢出限制影响。

## 实施范围

- `frontend/src/features/academic-flow/AcademicFlowDesigner.tsx`：仅为教师设计器根页面增加专用布局类。
- `frontend/src/styles.css`：建立固定视口的 Flex/Grid 高度链，移除设计器画布依赖视口计算的最小高度，并补充窄屏内部滚动规则。

学生填写页、流程列表页、后端接口、发布状态、节点权限和画布手势均不修改。

## 验证边界

按项目规范不运行自动测试、构建或浏览器插件。完成前仅进行 DOM/CSS 层叠、响应式覆盖、弹窗定位和静态差异审计；随后以本地方式重启服务并核对监听端口及进程工作目录。
