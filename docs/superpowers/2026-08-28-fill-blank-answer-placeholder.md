# 填空题标准答案占位文案

## 目标

“请输入答案”仅作为教师端填空标准答案输入框的视觉提示，不写入标准答案数据，也不参与判分。

## 交互规则

- 新建填空题和添加新空时，真实标准答案初始化为空。
- 空输入框显示“请输入答案”；获得焦点时隐藏提示，未输入内容并失焦后重新显示。
- 已有草稿中仅包含“请输入答案”的旧值按占位文案展示，首次聚焦时转换为空值。
- 前后端发布校验均不接受“请输入答案”作为有效标准答案。

## 范围

修改教师端填空答案编辑器、答题卡默认值和前后端标准答案校验；不改变数据结构、学生作答界面或判分算法。

## 验证边界

依照项目规范，不运行测试、类型检查或浏览器自动化。完成后仅进行静态调用链审计、差异检查、本地服务重启和监听进程核对。
