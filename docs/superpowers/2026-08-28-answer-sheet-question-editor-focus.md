# 答题卡题目编辑聚焦交互

## 目标

精简教师编辑题目时的重复信息和冗余操作，使注意力集中在题干 Markdown 编辑区域。

## 交互规则

- 题目卡标题栏不展示题干缩略文本，只保留题号、题型、分值、选项或填空数量、展开状态和操作菜单。
- 题干 Markdown 区域使用浅蓝背景与蓝色边框；进入源码编辑状态后进一步强化边框和聚焦光圈。
- 专属配色仅作用于题干，不改变选项 Markdown 编辑器。
- 题型由“添加单选题”“添加多选题”“添加填空题”确定，创建后不再提供题型切换控件。
- 题型仍在题目卡标题栏中作为只读信息展示。

## 范围

仅调整答题卡前端编辑器、局部样式和相关静态测试断言；不修改题目数据结构、判分逻辑、学生端或后端接口。

## 验证边界

依照项目规范，不运行测试、类型检查或浏览器自动化。完成后仅进行代码调用链审计、差异检查、本地服务重启和监听进程核对。
