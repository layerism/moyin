# 只读答题卡宽度对齐

## 需求

学生答题卡提交后，题目卡片应与上方得分卡左右边缘对齐，避免只读题目区域比得分卡宽。

## 原因

得分卡使用 `margin: 16px 24px 0`，而只读 `RuntimeAnswerSheet` 直接作为弹窗子元素渲染，没有对应的水平间距，因此题目区域总宽度比得分卡多 48px。

## 设计

- 仅为 `.runtime-answer-sheet.is-readonly` 增加左右各 24px、底部 24px 的外边距。
- 保留得分卡与题目列表之间现有的 14px 垂直间距。
- 不影响可填写答题卡；其间距继续由 `.runtime-node-form` 提供。
- 不修改 JSX、评分、提交、只读判断或教师预览入口。

## 验证边界

按照项目规则，本任务不运行自动测试、类型检查或浏览器插件；实施后通过选择器优先级、桌面与移动端规则以及 Git 差异进行静态审计。
