# 确认承诺节点紧凑化实施计划

## 目标

将确认承诺节点的扫描件模板、审核方式、审核标准和上传限制压缩为紧凑信息区，减少节点检查器的纵向占用，并与文件上传节点的视觉密度保持一致。

## 布局

1. 模板信息行：显示 DOCX 图标、文件名、大小及发布固化状态；草稿态保留替换和删除操作。
2. 审核控制行：使用紧凑分段选项展示直接通过、AI 通过/不通过、AI 评分，并在同一区域显示上传限制摘要。
3. AI 标准行：仅启用 AI 审核时显示两行高度的标准输入框，字符计数放在输入区域右下角。
4. 窄屏时按信息组换行，不引入横向滚动。

## 业务约束

- 保留 `scanAuditEnabled`、`scanAuditMode`、`scanAuditPrompt` 和 `templateAsset` 的既有更新逻辑。
- 发布后模板和审核模式继续不可修改；审核提示词是否可编辑继续由 `promptDisabled` 控制。
- 不修改学生端、后端接口、发布快照或审核任务逻辑。

## 修改范围

- `frontend/src/features/academic-flow/AcademicFlowDesigner.tsx`
- `frontend/src/styles.css`

## 验证边界

按项目约定仅执行静态业务逻辑审计和 Git 差异检查，不运行测试、构建或浏览器检查；完成后重启本地前后端服务。
