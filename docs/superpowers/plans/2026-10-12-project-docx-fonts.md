# 项目内 DOCX 字体

用户已确认：字体集中在 frontend/public/docx-fonts，优先项目指定字体，缺失时使用项目备用字体；不匹配操作系统字体，不使用 local()。依据根 MEMORY.md，在共享 DocxPreview 接入，所有模板、参考文件和人工审核入口一致，保留文件下载与权限行为。

采用浏览器 FontFace API 注册独立的 MoyinDocx 字体名称。按实际渲染的字体族、字重与样式加载所需资源，映射中文、英文及旧版字体名称；项目指定原版字体失败时加载随仓库分发的 Fandol 和 Liberation 备用文件，全部来源均在 /docx-fonts/。保留原版与备用字体的区别，不承诺备用字形等同 Windows 原版。

挂载隐藏预览后，在分页前统一替换正文、页眉页脚及生成编号的字体族，字体全部加载完成后再计算行高与分页。已加载字体按字体族和样式缓存，失败可重试。关闭渲染库自带的原字体名注册，防止与项目字体策略冲突；保留字重、斜体、字号、颜色等既有属性。未知字体使用项目宋体作为备用；项目备用资源也失败时停止预览，不能静默改用系统字体。浏览器对未覆盖字符的字形回退仍是实际边界。

提供原版文件位置说明、备用字体来源、版本、授权文件和校验值。项目尚无 Windows 原版字体，不能将已分发的开源备用字体描述为 Windows 原版。只提交本任务文件，不混入已有审核配置；实施前后各一次提交，不运行测试或浏览器，仅静态类型与逻辑审计。收尾清理本任务缓存，通过 bash deploy/run_dev.sh 重启并核对进程、端口。
