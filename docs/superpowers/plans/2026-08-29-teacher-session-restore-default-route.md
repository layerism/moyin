# 教师登录态恢复默认进入教务流程

## 目标

补齐教师已有登录态从根路径 `/` 恢复时的默认导航，使其与教师提交登录表单后的行为一致，进入 `/academic-flow`。

## 实施

1. 在 `frontend/src/App.tsx` 的认证恢复流程中识别“教师认证成功且当前为根路径 `/`”。
2. 使用历史记录替换导航到 `/academic-flow`，并同步应用路由状态。
3. 保留教师主动点击“OSS 云盘”进入现有首页的行为，不修改 OSS 页面、接口或数据。

## 验证

依项目规范不运行测试、构建或浏览器检查。仅审计认证恢复、显式 OSS 导航和路由状态同步调用链；完成后重启本地服务并核验 5173、8000 监听、命令、工作目录及启动日志。
