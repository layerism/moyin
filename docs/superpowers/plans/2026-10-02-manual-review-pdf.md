# 人工审核 DOCX / PDF 预览

用户已确认仅在人工审核窗口增加切换。默认 DOCX，首次 PDF 请求由服务端 LibreOffice 转换；前端保留两种预览及 PDF Blob，窗口内切换不重复转换，卸载时取消请求并释放 Blob。

复用当前原件接口的教师身份、审核节点与文件归属校验，正式与模拟审核共用。每次转换独立临时目录与 LibreOffice profile，90 秒超时终止进程组，响应结束或失败后清理临时文件。原件不修改。转换失败显示可重试错误。

沿用现有安装脚本的 LibreOffice 与字体依赖。按项目要求仅进行静态逻辑审计，不运行测试或浏览器；不声称 PDF 排版已验证。已有脚本配置修改不提交。
