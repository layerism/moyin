# 答题卡题干编辑态视觉对齐计划

## 目标

减少题目弹窗中题干由 Markdown 渲染态切换到源码编辑态时的字号、行高和输入框高度跳变。

## 已确认范围

- 仅调整 `frontend/src/styles.css` 中题目弹窗题干区域的局部样式。
- 渲染态与编辑态统一为 15px 字号、1.55 行高、相同内边距和稳定的最小高度。
- 编辑态不再随内容自动扩大，较长内容在输入框内滚动并保留纵向手动调整能力。
- 输入框继承现有页面字体，减少原生表单字体与 Markdown 正文的字形差异。
- 不修改选项编辑器、Markdown 数据、组件接口、KaTeX/Markdown 解析链或学生端排版。

## 静态审计

- 样式必须限定在 `.answer-sheet-question-dialog .answer-sheet-question-markdown`。
- 渲染态与编辑态的盒模型参数必须一致。
- 不运行测试或浏览器检查；完成后按项目约定重启本地服务并核对端口与工作目录。
