# 节点定时按钮显示时间

## 目标

节点未设置时间时显示“＋ 定时设置”；设置时间后，按钮直接显示对应时间窗口，旁边继续显示“定时开放 / 开放中 / 已截止”等状态。

## 显示规则

- 仅起始时间：`◷ YYYY/MM/DD HH:mm 开放`
- 仅截止时间：`◷ YYYY/MM/DD HH:mm 截止`
- 起始与截止时间：`◷ YYYY/MM/DD HH:mm → YYYY/MM/DD HH:mm`
- 时间字段无效或均为空：`＋ 定时设置`

- 修改 `frontend/src/features/academic-flow/AcademicFlowDesigner.tsx`。
- 增加本地时间格式化和按钮标签函数，按钮仍打开原有定时设置弹窗。
- 不修改时间字段、保存行为、弹窗校验、状态判定、发布后修订或后端接口。
- 按项目规范不运行测试、构建或浏览器，仅做静态逻辑和差异审计。
