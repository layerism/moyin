# PyMuPDF 导入兼容修复

## 原因与范围

重装后安装的 PyMuPDF 1.28.2 在导入 `fitz` 时向标准输出写入弃用警告，导致审核子进程的 JSON 输出协议校验失败。图片和 PDF 共用的处理模块均受影响。

## 已确认的实施方案

将后端五处 `import fitz` 改为 `import pymupdf as fitz`，保持现有调用方式、审核规则和 JSON 校验约束。无需降级或重新安装依赖。

## 审查与交付

- 检查所有旧导入及差异，遵循现有脚本内容哈希同步机制。
- 按项目约定不运行测试或浏览器验证，仅做静态审查。
- 创建实施前后检查点，通过 `bash deploy/run_dev.sh` 重启开发服务并核对监听端口及工作目录。
- 仅清理项目源码生成的缓存，保留虚拟环境及第三方依赖。
