# 答题卡紧凑表单式布局实施说明

## 目标

答题卡题目编辑区对齐现有表单字段卡片：使用紧凑摘要行与单题展开详情，减少题目较多时的纵向占用。

## 布局与交互

- 顶部同一行展示答题卡标题、总分和新增单选题/多选题/填空题操作。
- 评分策略保持单行紧凑布局。
- 每道题使用折叠卡片；默认折叠，新增题目自动展开，同一时间最多展开一道题。
- 摘要行展示拖拽柄、题号、题型、分值与选项/填空数量、必答、展开箭头和三点菜单。
- 三点菜单包含上移、下移和删除；删除保持危险操作颜色。
- 展开区保留原始 Markdown 编辑规则：聚焦显示源码，失焦原位渲染；不增加符号或图片按钮。
- 单选、多选选项使用紧凑行；正确答案选择器、Markdown 内容和三点删除菜单同排。
- 填空配置压缩为逐空行，保留标记、分值、可接受答案与大小写规则。
- 校验失败时摘要显示“需修正”，卡片使用现有红色错误语义。

## 范围

仅修改前端答题卡编辑组件、相关纯逻辑和样式；不修改答题卡数据结构、后端接口、自动判分或学生端渲染。

## 验证边界

遵循项目规范，不运行测试、构建或浏览器检查；仅执行 TypeScript 语法解析、CSS 解析、差异检查和业务逻辑审计，完成后本地重启前后端。
