# 文件上传节点紧凑限制栏计划

**目标：** 将发布后修订说明与文件限制卡片压缩为两行工具栏，减少节点设置弹窗的纵向占用。

## 设计

- 第一行使用浅黄色修订状态条：发布后修订、基本信息与时间重新发布生效、审核规则完成后立即生效。
- 第二行使用紧凑限制栏：文件类型开关/预设、脚本锁定状态、单文件大小上限。
- 使用项目内 CSS 绘制的小型字符图标，不增加图标依赖。
- 脚本锁定文件格式时，将格式和锁定状态合并展示，不再单独占一行说明。
- 窄屏允许限制栏内部换行，不恢复大卡片布局。

## 边界

- 仅修改 `AcademicFlowDesigner.tsx` 和 `styles.css`。
- 不修改发布修订、审核策略、文件扩展名或文件大小校验逻辑。
- 不运行测试、构建或浏览器；只进行 JSX/CSS 和业务逻辑静态审计。
