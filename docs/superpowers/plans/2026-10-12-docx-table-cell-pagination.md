# DOCX 长表格单元格跨页

用户要求继续实施已定位的 DOCX 分页修复。原文件的第 5 行包含 2110 个字符、10 个段落；旧分页器只按完整行拆分，失败后将剩余表格整体缩小。

修改共享 `docxPagination.ts`：冻结当前排版的表格宽度和列宽；优先沿不切断纵向合并的完整行边界分页；超高行及纵向合并组按单元格内容分页，先保留完整段落，长段落复用现有文本分片逻辑。续页克隆表格、表头、列和单元格属性，保留列合并、行合并与边框，已移到上一页的正文不重复。分片取消行和单元格的固定高度，以内容决定高度。

文字表格不再整体缩小。无法安全拆分的复杂内容返回明确的预览错误，建议下载原件查看；不可分割的纯图片保留原有比例缩放。每次分页必须消费内容，避免空白续页循环。普通段落分片、显式分页、纸张切换和工具栏缩放保留现有行为。

模板、参考文件和人工审核通过同一个 DocxPreview 自动采用修复。遵循根 MEMORY.md 的共享预览与任务范围约束，不改业务权限、原文件或用户已有后端配置。实施前后各提交一次检查点；仅做静态类型及逻辑审计，不运行测试、构建或浏览器验证；检查项目中间缓存，使用 `bash deploy/run_dev.sh` 重启并核对进程与端口。
