# 文件节点材料配置紧凑化实施计划

## 目标

将文件节点的“学生填写模板”和“预置审核脚本”合并为紧凑的材料配置面板，减少节点检查器纵向占用，并与文件限制、确认承诺节点保持一致的视觉密度。

## 布局

1. 材料配置标题行：使用紧凑图标和节点类型标识。
2. 模板行：显示文件类型、文件名、大小以及草稿态操作或发布固化状态。
3. 审核行：显示审核脚本选择器以及发布固化状态。
4. 参数区：普通参数采用双列紧凑布局；最大长度超过 500 字符的文本参数采用约 120 px 初始高度的多行输入框，允许纵向扩展并显示字符计数。
5. 窄屏时按信息组换行，不产生横向滚动。

## 业务约束

- 保留模板上传、替换、删除和文件类型约束的既有逻辑。
- 保留 `auditScriptId`、`auditScriptName`、`auditScriptType`、`auditScriptParams` 和脚本文件类型锁定逻辑。
- 发布后模板和审核脚本继续不可修改；脚本参数是否可编辑继续由 `parameterDisabled` 控制。
- 保留脚本列表加载失败和参数校验错误反馈。
- 不修改学生端、后端接口、发布快照或审核任务逻辑。
