# Windows DOCX 原字体文件

用户明确要求网络下载并接入宋体、黑体、仿宋、楷体_GB2312、华文行楷、Times New Roman 原字体，同时核对加粗。此前只有 Fandol/Liberation 备用字体，不能视为原版兼容已完成。

字体下载到 frontend/public/docx-fonts，不安装到 Linux 字体目录；原文件保留不转换。记录下载来源、固定版本、字体内部名称、样式、版本、SHA256；区分字体文件名称/元数据核对与官方来源、Web 分发授权核实。网络仓库存在文件不代表获得字体厂商的 Web 授权，不将第三方上传描述为微软官方下载或已取得授权。

复用现有私有字体族和项目文件优先加载机制。源码确认全局 :root 的 font-synthesis: none 会被 DOCX 预览继承，这是中文普通字重无法合成粗体的直接原因。仅在 section.docx 内启用 weight/style 合成，保留 XML 的 font-weight；Times New Roman 分别使用真正的普通、粗体、斜体、粗斜体文件。对于未成功取得的确切旧版字体，明确列出缺项，不能用新版楷体或 FandolKai 冒充楷体_GB2312。

截图中的封面布局差异单独按原 XML 审计，不混同为字体问题。共享预览、原文件下载和权限边界按根 MEMORY.md 保持一致。保留用户已有审核配置；实施前后各一次提交，只静态类型、字体元数据和逻辑审计，不运行测试或浏览器，完成后以 deploy/run_dev.sh 重启服务并清理本任务中间内容。
