# DOCX 分页后的页码域更新

用户已确认修复续页页码重复。复用共享 DocxPreview，遵循根 MEMORY.md 的预览一致性、任务范围提交和本地服务约束，不修改原文件或下载行为。

在渲染前识别页眉、页脚中的 PAGE、NUMPAGES 和 SECTIONPAGES 域，支持复杂域与简单域，为域结果添加独立标记，保留原有文字与样式。正文块携带所属节编号；分页后根据实际页面顺序更新标记，仅首次进入新节时采用其显式起始页码，未指定则连续编号。支持十进制、前导零、罗马数字、字母及不显示编号，域中的明确数字格式优先。

页脚中的其他数字不能按文本匹配替换。总页数采用浏览器实际分页数量，仍不承诺与 Word 一致。保留已有不支持域的渲染行为。

实施前后各提交一次检查点；仅静态类型、差异和业务逻辑审计，不运行测试或浏览器。完成后检查限定缓存，通过 bash deploy/run_dev.sh 重启并核对进程、端口。
