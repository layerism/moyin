# Node Description Visibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hide node descriptions from teacher and student overview cards while preserving them in teacher settings and student runtime dialogs.

**Architecture:** Remove only the three overview-card description elements. Keep the persisted `requirement` field and both detail surfaces unchanged, then simplify card grid styles that previously reserved a description row.

**Tech Stack:** React, TypeScript, CSS.

## Global Constraints

- Keep node descriptions editable and persisted.
- Keep the complete description in the student runtime dialog.
- Do not change click, double-click, selection, or disabled behavior.
- Preserve adaptive teacher-node height measurement and connection geometry.
- Do not run tests, builds, or browser automation; perform static business-logic audit only.
