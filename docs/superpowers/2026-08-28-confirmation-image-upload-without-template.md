# 确认承诺节点无模板图片提交

## 目标

确认承诺节点启用 AI 审核时，教师可以不提供 DOCX 模板，学生直接上传数学稿纸、手写过程等图片材料。

## 业务规则

- 教师启用 AI 审核时，DOCX 模板可选；发布仍要求审核模式和审核标准完整。
- 有模板时，学生必须先下载模板，再上传以模板文件名开头的 JPG、JPEG 或 PNG 图片。
- 无模板但启用 AI 审核时，学生直接上传 JPG、JPEG 或 PNG 图片，不限制文件名前缀。
- 无模板且选择直接通过时，学生只需确认承诺，不要求上传图片。
- 需要图片时，学生必须确认承诺并至少上传一张图片；沿用现有数量、页数和大小限制。

## 实施范围

- 统一后端“需要扫描件”的判断，并使模板文件名校验支持无模板情形。
- 调整发布校验、学生上传与提交、教师材料导出逻辑。
- 调整教师配置提示及正式学生端、教师预览共用的图片上传界面。
- 不新增数据库表、节点类型或 API。

## 验证边界

依照项目规范，不运行测试或浏览器自动化。完成后进行前后端调用链静态审计、差异检查，并以本地非 Docker 方式重启服务和核对监听进程。
