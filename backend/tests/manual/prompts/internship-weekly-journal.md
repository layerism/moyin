# 审核范围

只审核学生需要填写的内容。不要检查“专业实习周记评阅意见”、教师签名、评阅教师填写内容或评分。

# 封面与学生信息

- “年级班级”不得为空，也不得保留 `202X 级 X 班` 等模板占位内容；不符合时说明应填写真实年级和班级。
- “学号”不得为空；不符合时说明应填写本人完整学号。
- “姓名”不得为空；不符合时说明应填写本人真实姓名。

# 专业实习基本信息表

- “实习单位”不得为空；不符合时说明应填写实习单位全称。
- 实习单位地址不得为空，至少应填写省、市、区县及具体街路信息；不符合时说明缺少的地址内容。

# 第 1 周专业实习周记表

- “实习单位”、周记起止日期以及“工作任务及心得体会”均不得为空。
- “工作任务及心得体会”应包含本周完成的主要工作和个人体会，不能只保留表格标题或模板文字。

# 第 2 周专业实习周记表

- “实习单位”、周记起止日期以及“工作任务及心得体会”均不得为空。
- “工作任务及心得体会”应包含本周完成的主要工作和个人体会，不能只保留表格标题或模板文字。

- “工作任务及心得体会”应包含本周完成的主要工作和个人体会，不能只保留表格标题或模板文字。
