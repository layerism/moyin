# DOCX 视觉排版审核

在文件节点添加「AI 通过/不通过」审核，选择本脚本，填写排版审核要求并绑定支持图片输入的视觉模型。只接受 DOCX；无需手动转 PDF 或截图。

流程：LibreOffice 独立配置目录转 PDF → PyMuPDF 按物理页序生成 PNG → 分批视觉审核 → 汇总通过/不通过。默认每批 4 页，后续批次复用上一批末页作上下文，只报告本批新页的问题，跨批问题归属新页。

不通过结果包含文件名、实际页码、位置、问题与修改建议。全部文件和页面审核完成才产生业务结论。页数超限、转换失败、模型无法辨认、响应字段/页码错误、超时均走审核异常与重试流程，不视作排版不合格。

管理端默认：总页数 40、图片最长边 2000 px、每批 4 页、转换超时 60 秒、单批请求超时 90 秒、整项超时 1200 秒、并发 2。页数与批次调大时应相应调整总超时；不会在超时后使用部分审核结果。

依赖现有 PyMuPDF、LibreOffice Writer 和中文字体。Ubuntu 可安装 `libreoffice-writer fonts-noto-cjk`。图片按需逐批加载，中间 PDF、PNG 和独立 LibreOffice 配置位于任务临时目录；任务结束清理，取消/超时终止整组子进程。

结论基于服务器 LibreOffice 渲染，不保证与本地 Word 排版完全相同。精确字体、字号、页边距数值应另用 DOCX 结构检查，不能凭图片推断。本脚本只审核，不修改原文件。
